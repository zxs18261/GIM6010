# Requirements: GIM6010 VOFA调试通信

## Project Summary

当前固件持续发送36通道JustFloat，启动、预定位、Flash读取和故障过程不便观察，动态调试时通道数量和串口占用也过高。本需求面向GIM6010电机控制器的调试操作者，将通信分成两个由操作者手动切换的阶段：运行前使用RawData文本查看关键事件和静态参数，需要动态波形时使用精简JustFloat。所有查询和数据流切换必须与电机控制量解耦。

本阶段的目标是：

- 启动、预定位、Flash读取和故障阶段使用RawData文本。
- 需要观察动态波形时，手动切换到JustFloat。
- JustFloat精简为14个开环通道。
- 可主动查询固件、校准Flash和本次启动日志。
- 所有通信操作不得意外改变电机控制量。
- 后续每个调试阶段提供“发送什么、得到什么、如何判断以及何时停机”的明确引导。

## Functional Requirements

### 通信状态与文本事件

1. **COM-01**：控制器复位后默认进入TEXT状态，不自动发送JustFloat。
2. **COM-02**：关键事件以UTF-8结构化文本输出，每行以`\r\n`结束，并同时包含消息类型、复位后毫秒时间、稳定ASCII事件代码和中文说明。例如：

   ```text
   @EVT,1250,CAL_START,正在预定位
   @EVT,3470,CAL_SAVE_OK,校准数据保存成功
   @FAULT,8160,UNDERVOLTAGE,母线欠压
   ```

3. **COM-03**：必须记录启动、母线等待、Flash读取、预定位步骤、校准保存、待机、模式变化、数据流变化、命令拒绝和故障事件。
4. **COM-04**：事件保存在RAM环形队列中，仅覆盖本次上电周期；队列满时覆盖最旧记录并统计溢出次数，不将运行事件写入Flash。

### 查询与控制命令

5. **COM-05**：支持以下只读查询命令：

   - `HELP?`：显示命令、格式、单位和用途。
   - `INFO?`：读取固件身份、状态、模式、母线、电机参数、速度/电流/转矩限值及数据流状态。
   - `CAL?`：读取Flash校准有效性、epoch、程序签名、校验结果、角度偏置、方向参数、电流映射和极对数。
   - `LOG?`：输出本次上电事件及日志溢出次数。
   - `STREAM?`：查询当前为TEXT、STARTING、JUSTFLOAT或STOPPING状态。

6. **COM-06**：使用独立命令控制JustFloat：

   - `STREAM=1?`：请求启动JustFloat。
   - `STREAM=0?`：停止JustFloat。
   - 切换数据流不得修改`AO/BO/CO/VO`、DQ电压、控制模式、PWM或MOE。

7. **COM-07**：`STREAM=1?`仅在校准完成后的安全待机状态4允许执行；其他状态必须拒绝并记录原因。`STREAM=0?`在任何状态都可执行。
8. **COM-08**：普通停机不会自动关闭数据流，以便观察停机后的动态；复位和故障会自动停止JustFloat并记录事件。
9. **COM-09**：JustFloat运行期间禁止插入任何文本。`INFO?/CAL?/LOG?/HELP?/STREAM?`等查询不能破坏二进制帧；需要先发送`STREAM=0?`并切回RawData后再查询。
10. **COM-10**：保留既有控制命令及其普通十进制浮点数格式：

    ```text
    AO=<普通十进制浮点数>?
    BO=<普通十进制浮点数>?
    CO=<普通十进制浮点数>?
    VO=<普通十进制浮点数>?
    ```

11. **COM-11**：`%f`、NaN、Inf、科学计数法、残缺、超长及未知命令必须无副作用拒绝，不得产生新的非零运动命令。

### JustFloat通道合同

12. **COM-12**：JustFloat固定为14个小端`float`，末尾追加`00 00 80 7F`：

    - Ch0：状态码。
    - Ch1：控制模式。
    - Ch2：母线电压`[V]`。
    - Ch3：实际使用的`Ud [V]`。
    - Ch4：实际使用的`Uq [V]`。
    - Ch5：`Id [A]`。
    - Ch6：`Iq [A]`。
    - Ch7：限幅后的输出轴目标速度`[rad/s]`。
    - Ch8：开环角度积分实际使用的输出轴速度`[rad/s]`。
    - Ch9：编码器测得的输出轴速度`[rad/s]`。
    - Ch10：SVPWM电角度`[rad]`。
    - Ch11：编码器电机轴机械角度`[rad]`。
    - Ch12：TIM1实际MOE状态。
    - Ch13：JustFloat实际发送频率`[Hz]`。

13. **COM-13**：极对数、方向、Flash校准数据、转速/转矩限值等静态或低频数据通过`INFO?`和`CAL?`查询，不再持续占用JustFloat通道。

### 调试导航

14. **DBG-01**：上电检查时，调试引导应依次说明以下命令的用途：

    ```text
    HELP?
    INFO?
    CAL?
    LOG?
    ```

    它们分别用于了解命令、当前状态、Flash校准参数和完整启动过程。

15. **DBG-02**：观察动态波形时采用以下流程：

    1. 在RawData中用`INFO?`确认状态为4、Ud和Uq均为0。
    2. 将VOFA切换为JustFloat。
    3. 发送`STREAM=1?`。
    4. 确认14条曲线开始刷新。
    5. 再根据具体实验发送安全的`AO/VO/BO/CO`命令。

16. **DBG-03**：停止观察时采用以下流程：

    1. 在JustFloat界面发送`STREAM=0?`。
    2. 切回RawData。
    3. 发送`STREAM?`确认停止。
    4. 发送`LOG?`查看期间是否发生故障或命令拒绝。

17. **DBG-04**：后续每次台架调试引导必须明确给出：

    - 电源电压和限流要求。
    - 电机是否允许空载转动。
    - 应发送的具体命令顺序。
    - 应重点观察的通道。
    - 正常范围和通过标准。
    - 过流、抖动、异响、MOE异常等立即断电条件。

## Non-Functional Requirements

1. **NFR-01**：USART1保持921600-8N1。
2. **NFR-02**：14通道JustFloat帧长为60字节，目标发送频率为500 Hz；在921600-8N1链路上占用率约32.6%。
3. **NFR-03**：UART TX只能有一个DMA所有者，文本和JustFloat不得同时占用DMA，也不得交叉写入同一帧。
4. **NFR-04**：中断中只记录事件码，不格式化中文、不等待串口、不访问或写入Flash；文本构造、查询应答和DMA调度在非高频中断路径执行。
5. **NFR-05**：保持SguanFOC现有代码风格；所有代码增删必须写有意义的中文备注，说明用途、单位、方向、限幅或安全原因。
6. **NFR-06**：实现后同步更新源码、VOFA协议文档、通道说明和调试指南。
7. **NFR-07**：完成真实Keil全量编译，要求0错误、0警告；编译通过不等于台架验证通过。
8. **NFR-08**：查询和数据流切换必须验证不会使电机转动、产生非零DQ命令或开启MOE。
9. **NFR-09**：实际带电验证必须使用受限母线和限流电源，并遵守每次调试给出的立即停机条件。

## Edge Cases

1. **EDGE-01**：控制器尚未完成初始化、正在预定位或处于故障状态时收到`STREAM=1?`，必须保持当前安全输出并拒绝启动数据流。
2. **EDGE-02**：JustFloat正在发送时收到文本查询，不得把文本插入二进制帧，也不得因此改变电机控制量；操作者应先停止数据流再查询。
3. **EDGE-03**：收到`STREAM=0?`、复位或故障时，必须安全结束当前DMA帧并停止后续JustFloat发送，不覆盖正在发送的缓冲区。
4. **EDGE-04**：上位机连接较晚而错过启动文本时，可通过`LOG?`读取当前上电周期的历史事件。
5. **EDGE-05**：RAM日志队列满时覆盖最旧事件并增加溢出计数，不能阻塞控制路径。
6. **EDGE-06**：非法、残缺、过长或无法解析的命令必须无副作用；字面量`VO=%f?`不得改变速度、转矩作用量、模式或PWM状态。
7. **EDGE-07**：待机、数据流切换及故障状态下，TIM1实际MOE必须符合安全要求。当前已发现TIM1自动输出AOE可能使MOE重新置位，该问题必须在带母线运动测试前解决。

## Out of Scope

- 跨掉电故障日志。
- Flash擦除或远程强制重新预定位。
- 在线修改电机固定参数。
- 电流环、速度环和位置环专用通道组。
- RawData与JustFloat自动识别或自定义复合协议。
- 第二路调试串口。

## Open Questions

无。实现阶段可在不改变上述行为合同的前提下确定RAM事件队列容量和内部模块划分。

## Notes

- 当前阶段为Stage 1可观测性需求确认；需求已由用户批准，尚未授权修改固件代码、烧录或带电测试。
- 当前36通道JustFloat约占921600链路的80.3%；精简后的14通道约占32.6%。
- 本阶段只定义开环调试通道；后续进入电流环、速度环或位置环时另行定义对应通道合同。
- 实现后的最小验证信号是：复位后RawData事件可读；状态4下可启动14通道JustFloat；停止或故障后无文本/二进制混帧；所有查询和数据流切换均保持零输出安全语义。
- 出现电源过流保护、异常噪声、剧烈抖动、失控转动或待机/故障时MOE仍为1，应立即撤销母线并保留日志。
