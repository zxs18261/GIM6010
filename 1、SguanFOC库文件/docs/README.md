# GIM6010工程文档

本目录是工程说明、FOC调试证据、设计决策和实施计划的统一入口。固件实际运行值仍以当前源码和`GIM6010_V0.0.ioc`为第一权威来源；文档负责解释来源、适用范围和验证状态。

## 入口

- [AI快速接入与开发交接](foc/ai-development-handoff.md)：新AI/工程师的第一入口，包含当前设计流程、关键源码、授权边界、验证闭环和交接模板。
- [FOC调试与项目档案](foc/README.md)：参数、术语、VOFA、控制映射、阶段状态、校准和调试记录。
- [架构决策](adr/)：难以逆转、未来容易被误解的长期决策。
- [实施计划](superpowers/plans/)：多步骤修改和文档建设计划。
- [EIDE环境问题排查与解决](EIDE环境问题排查与解决.md)：构建环境专项记录。

## 维护原则

- 当前源码/`.ioc`与文档冲突时，先查明原因再更新文档，不静默选择旧值。
- 台架结论必须记录硬件、固件、母线、限流、命令、测量和原始数据路径。
- 未经当前修订复验的历史成功，只能标记为“用户反馈/待回归”，不能写成当前固件已验证。
- 具体电机和控制板常量留在本仓库；跨项目复验后的方法才可提升到个人`STM32_FOC_Debugging` Skill。
