# GIM6010电机控制语境

本文件只统一项目特有术语。参数、源码实现和实验过程分别放在项目档案、源码映射和调试记录中。

## Language

**电机轴**：
电机转子直接连接的一侧；当前MT6816安装在这一侧。
_避免_：在未说明参考轴时只写“转子轴”或“机械轴”。

**输出轴**：
8:1减速器的机械输出侧，也是VOFA对外速度命令的默认参考轴。
_避免_：负载轴、关节轴，除非已经进入具体机械臂应用语境。

**电机轴机械角**：
编码器直接测得或展开后的电机转子角度，单位必须注明rad或deg，并注明单圈或连续。
_避免_：编码器角度，除非同时说明是否已应用方向和零偏。

**输出轴机械角**：
由电机轴连续机械角按减速比换算得到的减速器输出侧角度；它不是机械限位归零后的关节绝对位置。
_避免_：机械臂零位。

**电角度**：
用于Park/反Park和SVPWM的周期角度，按电机轴机械角、极对数、方向和电角度偏置形成。
_避免_：在未说明坐标约定时只写“FOC角度”。

**开环FOC**：
`Ud=0`、`Uq`独立给定，电角度由输出轴速度命令换算并积分生成的运行方式；编码器只用于观测或进入开环时的平滑接管，不闭合速度环。
_避免_：V/f控制。

**开环转矩作用量**：
开环模式中的`Uq`电压命令，单位V；它会影响电流和可产生转矩，但不是经过标定的N·m转矩命令。
_避免_：开环转矩，除非明确说明只是作用量。

**电流模式转矩作用量**：
电流模式中的目标`Iq`，单位A；只有扭矩常数、轴侧定义和损耗经过验证后才能换算为可信N·m。
_避免_：精确转矩命令。

**项目基线**：
当前仓库中已经按证据等级整理的项目事实、接口和验证状态集合。
_避免_：把个人Skill中的缓存副本视为权威来源。

**装配校准**：
绑定具体控制板、电机、编码器安装和三相接线关系的方向、映射及电角度偏置数据。
_避免_：仅称“预定位”，因为预定位只是校准流程的一部分。

**机械臂归零**：
应用层通过限位、零位传感器或机械基准确定关节坐标的过程；不等于电机电角度校准。
_避免_：电机预定位。
