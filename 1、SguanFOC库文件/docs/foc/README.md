## 证据标签

- **bench-verified**：在写明的硬件、固件和供电条件下重复通过。
- **source-confirmed**：当前源码或配置明确如此，但尚未完成当前修订实物验证。
- **user-reported**：用户确认曾在某一修订观察到，尚缺完整原始条件或当前回归。
- **hypothesis**：有预测和验证方法，尚无结论。
- **rejected**：实验已否定，保留以免重复走弯路。
- **hardware-specific**：只适用于指定板、电机、编码器安装或接线。
- **generalized**：至少跨一个有意义差异的工程复验，且适用边界明确。

## 更新触发

- 修改参数、单位、方向、引脚、频率、限幅或协议：同步更新项目档案及相关契约。
- 完成一次带电实验：新增调试或阶段记录，并更新阶段状态。
- 生成或失效一份Flash校准：新增校准实例记录。
- 确认一个难以逆转且存在真实取舍的决策：新增或替代ADR。
- 发现跨项目可复用经验：先记录候选；只有用户明确要求且完成复验后才更新个人Skill。
