# 装配校准记录

Flash保存的是具体“控制板+电机+编码器安装+三相接线”的实例数据，本目录保存其可追溯镜像。源码默认方向不能替代有效校准记录。

## 当前状态

尚无一份绑定控制板ID、电机ID、固件签名和实测结果的完整校准实例文档。当前代码定义的Flash格式和流程为**source-confirmed**，台架结果为**pending**。

## 命名

新记录使用：

```text
<controller-id>-<motor-id>-<YYYY-MM-DD>.md
```

如果硬件没有序列号，应使用可粘贴到实物上的人工标签，不用“当前板”“这个电机”等会失去含义的名称。

## 必须重新评估校准的变化

- 更换电机或编码器。
- 改变编码器安装方向、磁环或传动关系。
- 交换U/V/W相线，修改PWM相映射、极性或死区策略。
- 修改Ia/Ib/Ic采样通道、符号、增益或Clarke/Park方向约定。
- 修改极对数、电角度公式、偏置定义或校准数据结构。
- 固件签名或`USER_CALIBRATION_EPOCH`变化导致Flash记录无效。

## 新建记录

复制[校准记录模板](../templates/calibration-record-template.md)。记录中的Flash解码值必须来自当前固件读回或调试器，不从源码默认值抄成“实测”。
