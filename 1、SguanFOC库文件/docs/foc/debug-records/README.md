## 新建记录

复制[故障记录模板](../templates/debug-record-template.md)。不要覆盖旧记录；同一问题的新修订回归应新建文件，并在两份记录之间互相链接。

## 关闭条件

问题只有同时满足以下条件才标为resolved：根因被证据支持；修复与根因对应；原始现象不再复现；相关安全零输出路径通过；当前固件和硬件身份已记录；不存在被修复掩盖的第二个故障。
