# VOFA通信契约

本文件是GIM6010当前VOFA上下行接口的项目权威说明。未经用户明确批准，不得重排或复用现有通道；新增通道从末尾追加，并同步修改源码、`CH_COUNT`、带宽说明和上位机配置。

## 物理与帧格式

- USART1，921600 baud，8 data bits，1 stop bit，无校验、无硬件流控。
- 上行JustFloat：36个IEEE-754小端`float`，随后是`00 00 80 7F`，总长148 byte。
- 目标发送频率500 Hz；921600-8N1理论线速92160 byte/s，148×500=74000 byte/s，约占80.3%。
- Ch6显示相邻两次成功启动UART TX DMA之间的20 kHz计数差换算结果；首个成功帧为0 Hz。它不是VOFA界面刷新率。

## ASCII下行命令

格式仅接受：

```text
AO=<普通十进制浮点数>?
BO=<普通十进制浮点数>?
CO=<普通十进制浮点数>?
VO=<普通十进制浮点数>?
```

允许可选正负号、数字和最多一个小数点。`%f`、NaN、Inf、科学计数法、空数字、残缺、超长或未知命令必须丢弃，并且不得改变模式、状态或任何目标量。

## 命令语义

- `BO<1`：开环FOC；`AO`为Uq[V]，`VO`为输出轴速度[rad/s]。
- `1≤BO<2`：电流环；`AO`为目标Iq[A]，限于±6.6 A连续额定值。
- `2≤BO<3`：速度-电流双环；`AO`为输出轴目标速度[rad/s]，限于±30.787608 rad/s。
- `BO≥3`：位置-速度-电流三环；`AO`为目标位置[rad]，具体参考轴和连续角语义在位置环启用前仍需验证。
- `CO<0.5`：清零Ud/Uq、Id/Iq、速度和位置目标，转入STANDBY并关闭PWM输出。
- `CO≥0.5`：请求重新进入未初始化流程，仍服从母线、编码器、校准和故障门控。
- 校准等待、校准执行或故障状态下，运动命令不得预存成校准结束后的自动动作。

## 36个上行通道

- Ch0：电机状态机编号，无单位。
- Ch1：输出轴实测机械角速度，rad/s。
- Ch2：输出轴目标机械角速度，rad/s。
- Ch3：d轴电流Id，A。
- Ch4：q轴电流Iq，A。
- Ch5：U相逻辑PWM比较值，count，范围约0～4249。
- Ch6：实际成功启动DMA的数据帧率，Hz，首帧为0。
- Ch7：q轴电压给定Uq，V。
- Ch8：A相实际电流Ia，A。
- Ch9：PLL估算的相对机械位置，rad；当前参考轴/连续性需结合模式验证。
- Ch10：机械零位偏置，rad。
- Ch11：控制模式，0开环、1电流、2速度-电流、3位置-速度-电流。
- Ch12：母线电压，V；ADC未就绪时回退配置值，0 V有效测量不回退。
- Ch13：SVPWM实际使用的电角度，rad；开环时为积分角。
- Ch14：MT6816电机轴单圈机械角，rad，约0～2π。
- Ch15：Ch13角度制显示，deg。
- Ch16：Ch14角度制显示，deg。
- Ch17：最近被接受并进入`User_AO_Adjust`的原始AO；单位随模式为V、A、rad/s或rad。
- Ch18：开环经过软件限幅后真正用于角度积分的输出轴速度，rad/s；非有效开环状态显示0。
- Ch19：输出轴瞬时峰值转矩常量12.39 N·m，不表示当前实际转矩。
- Ch20：输出轴软件命令速度上限30.787608 rad/s。
- Ch21：校准结果码：0未判定、1等待母线、2正在校准、3本次校准并保存成功、4从Flash加载、5编码器失败、6相序检查失败、7 Flash保存/回读失败。
- Ch22：本次上电实际施加的对齐Ud，V；新校准当前配置约0.96 V，从Flash加载时为0 V。
- Ch23：最终相序检查结果：1通过、0未运行/失败、-1方向相反；若自动翻转后复测通过，最终为1。
- Ch24：校准Flash有效标志；成功加载或保存回读后为1。
- Ch25：母线ADC有效标志；至少收到一个注入组Rank3样本后为1。
- Ch26：MCU复位后未滤波母线最小采样，V；用于捕获500 Hz Ch12容易漏掉的启动瞬态。
- Ch27：最终`Encoder_Dir`，1或-1。
- Ch28：最终`Motor_Dir`，1或-1。
- Ch29：最终`PWM_Dir`，1或-1。
- Ch30：最终`Current_Dir0`，1或-1。
- Ch31：最终`Current_Dir1`，1或-1。
- Ch32：最终`Current_Num`，0=AB、1=AC、2=BC。
- Ch33：电机极对数；当前GIM6010应为14。
- Ch34：TIM1硬件MOE状态；1=功率PWM允许，0=三相主输出关闭。预定位完成、待机和故障后必须为0。
- Ch35：当前d轴电压给定Ud，V；预定位释放后必须为0。

## 上位机与记录要求

- 保存数据时同时记录固件HEAD、工作区是否脏、串口配置、VOFA工程版本、采样起止时间和下发命令。
- 原始CSV/截图不得只用“正常/异常”命名，应由调试记录链接并说明观察通道。
- 改变`CH_COUNT`后必须重新计算总帧长度和带宽，并验证DMA缓冲结构大小。
