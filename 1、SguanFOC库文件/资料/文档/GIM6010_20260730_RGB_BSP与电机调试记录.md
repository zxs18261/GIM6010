## 2. SguanFOC 电机实物分阶段调试

依据 SguanFOC 官方调试流程图（开环 → 电流环 → 速度环 → 位置环），结合 GIM6010 工程现状整理如下。

### 2.1 调试阶段与模式对照

| 流程图阶段 | SguanFOC 宏 | 值 | 说明 |
|:----------:|-------------|:--:|------|
| 开环调试 | `Velocity_OPEN_MODE` | 0 | 验转向、编码器速度、电流方向 |
| 电流闭环 | `Current_SINGLE_MODE` | 1 | 力矩/电流跟随 |
| 速度闭环 | `VelCur_DOUBLE_MODE` | 2 | 速度-电流双闭环 |
| 位置闭环 | `PosVelCur_THREE_MODE` | 3 | 位置-速度-电流三环 |

### 2.2 各阶段要点

**阶段 1 — 开环（mode 0）**

- 设置 `Sguan.foc.Uq_in` ≈ 额定母线电压的 **10%**（24V 电机约 2.4V）
- 检查三项：
  1. 电机是否平稳旋转 → 不对则调 `Encoder_Dir` / `Motor_Dir`
  2. 串口观察 `Sguan.encoder.Real_Speed` 波形
  3. 堵转时 `Sguan.current.Real_iq` 应为稳定正值 → 反了交换 `Current_Dir0/1`

**阶段 2 — 电流环（mode 1）**

- 在 **10kHz** 中断中调用 `SguanFOC_High_Loop()`
- 电流环带宽 ≈ 控制频率的 1/10（10kHz 控制 → 约 2kHz 带宽）
- PI 参数（内模法）：`Kp = Wc × L`，`Ki = Wc × Rs`（在 `UserData_Parameter.h`）

**阶段 3 — 速度环（mode 2）**

- 在 `UserData_Config.h` 通过 `Open_PI_Control` 选择 PI 或 STA 速度环

**阶段 4 — 位置环（mode 3）**

- 位置 → 速度 → 电流 三环级联

### 2.3 软件架构（标准挂接）

```
main while(1)          → SguanFOC_main_Loop()
TIM1/ADC 10kHz 中断    → SguanFOC_High_Loop()
TIM2 1kHz 中断         → SguanFOC_Low_Loop()
USART 接收             → SguanFOC_Printf_Loop()
```

## 3. 参考工程 RGB 代码解析（`手搓与AI编写`）

### 3.1 架构

```
电机状态 g_Mc / g_Params / PROT
        ↓
  app_led.c（自动读状态决定灯效）
        ↓
  bsp_ws2812.c（TIM4_CH2 + DMA）
        ↓
  板载 1 颗 WS2812（PA12）
```

### 3.2 参考工程灯语（app_led 自动模式）

| 状态 | 灯效 |
|------|------|
| 故障 | 红色计数闪烁，次数 = 故障码 |
| 校准中 | 蓝色快闪 5Hz |
| MIT 运行 | 青色常亮 |
| 其他运行 | 绿色常亮 |
| 温度告警 | 黄色 |
| 空闲已校准 | 绿色呼吸 2s |
| 空闲未校准 | 白色呼吸 2s |

### 3.3 与本工程的设计差异

本工程 **不采用** `app_led.c` 的「自动读电机状态」方式，改为：

- **BSP 只负责驱动 + 无状态灯效辅助函数**
- **灯语由用户在 `UserData_Status.h` 各 `MOTOR_STATUS_xxx_Loop()` 中自行编写**

## 4. BSP_RGB 模块（当日新建）

### 4.1 设计约束（用户确认）

| 约束 | 说明 |
|------|------|
| 不读电机状态 | BSP 内部不访问 `Sguan.status` / `g_Mc` 等 |
| 状态机外置 | 在 `MOTOR_STATUS_xxx_Loop()` 中调用 API |
| 无掉电保存 | 亮度仅运行时有效，不写 Flash |
| TIM4 专用 | Init 时重配 TIM4 为 WS2812 800kHz 时序 |
| 文件位置 | `BSP/BSP_RGB.c`、`BSP/BSP_RGB.h` |

### 4.2 硬件参数

| 项目 | 值 |
|------|-----|
| 灯珠 | WS2812B × 1 |
| 数据脚 | **PA12 = TIM4_CH2** |
| DMA | **DMA1_Channel3** |
| 系统时钟 | 170 MHz |
| WS2812 ARR | 211 |
| 0 码 CCR | 58 |
| 1 码 CCR | 136 |
| 颜色顺序 | GRB（`BSP_RGB_ORDER_RGB = 0`） |
| 默认亮度 | 40 / 255 |

### 4.3 API 一览

**驱动层：**

```c
void    BSP_RGB_Init(void);
void    BSP_RGB_Poll(void);                    // 主循环必须调用
void    BSP_RGB_SetColor(uint8_t r, uint8_t g, uint8_t b);
void    BSP_RGB_SetColorRGB(uint32_t rgb);
void    BSP_RGB_SetBrightness(uint8_t brightness);
uint8_t BSP_RGB_GetBrightness(void);
void    BSP_RGB_Off(void);
void    BSP_RGB_DmaIRQHandler(void);           // 中断转发
```

**灯效辅助（无状态机，供状态 Loop 使用）：**

```c
uint8_t BSP_RGB_BreathLevel(uint32_t tick, uint32_t periodMs);
uint8_t BSP_RGB_BlinkOn(uint32_t tick, uint32_t halfPeriodMs);
uint8_t BSP_RGB_FaultBlinkOn(uint32_t tick, uint8_t blinkCount,
                             uint32_t halfPeriodMs, uint32_t pauseMs);
void    BSP_RGB_SetColorLevel(uint8_t r, uint8_t g, uint8_t b, uint8_t level);
```

**预定义颜色宏：** `BSP_RGB_COLOR_RED/GREEN/BLUE/CYAN/YELLOW/ORANGE/WHITE/OFF`

### 4.4 与 SguanFOC 状态机对接方式

`SguanFOC_Low_Loop()` → `MotorStatus_Loop(&Sguan.status)` → 调用对应 `MOTOR_STATUS_xxx_Loop()`。

在 `UserData_Status.h` 中示例：

```c
static inline void MOTOR_STATUS_IDLE_Loop(void){
    uint8_t lv = BSP_RGB_BreathLevel(HAL_GetTick(), 2000U);
    BSP_RGB_SetColorLevel(0U, 255U, 0U, lv);   /* 绿色呼吸 */
}

static inline void MOTOR_STATUS_CALIBRATING_Loop(void){
    if (BSP_RGB_BlinkOn(HAL_GetTick(), 100U)) {
        BSP_RGB_SetColorRGB(BSP_RGB_COLOR_BLUE);
    } else {
        BSP_RGB_Off();
    }
}
```

主循环仍需 **`BSP_RGB_Poll()`** 完成 DMA 刷新（与状态 Loop 分工：状态 Loop 设颜色，Poll 发波形）。

## 6. 上电呼吸灯测试（main 函数，已实测通过）

### 6.1 初始化（`USER CODE BEGIN 2`）

```c
MX_TIM4_Init();
/* ... 其他外设 ... */
BSP_RGB_Init();
```

### 6.2 主循环（`while(1)`）

```c
while (1)
{
    /* 呼吸灯：periodMs 为完整周期 [ms] */
    uint8_t breath = BSP_RGB_BreathLevel(HAL_GetTick(), 1000U);
    BSP_RGB_SetColorLevel(255U, 255U, 255U, breath);  /* 白色呼吸，可改 RGB */
    BSP_RGB_Poll();

    SguanFOC_main_Loop();
}
```

**要点：**

1. `BSP_RGB_BreathLevel()` 的返回值必须传给 `BSP_RGB_SetColorLevel()`，否则灯不会变化
2. 每轮循环必须调用 `BSP_RGB_Poll()` 才能通过 DMA 刷新 WS2812
3. 仅测灯时可暂时注释 `SguanFOC_main_Loop()`

### 6.3 可调参数

| 参数 | 示例 | 效果 |
|------|------|------|
| 呼吸周期 | `1000U` / `2000U` | 1s / 2s 一周期 |
| 颜色 | `(0,255,0)` 绿 / `(255,255,255)` 白 | 改变灯色 |
| 全局亮度 | `BSP_RGB_SetBrightness(80)` 在 Init 后 | 整体变亮/变暗 |

## 7. 知识点：`HAL_GetTick()`

| 项目 | 说明 |
|------|------|
| 含义 | HAL 库毫秒计时，上电后递增 |
| 单位 | ms（`uint32_t`） |
| 来源 | SysTick 1ms 中断 → `HAL_IncTick()` |
| 用途 | 呼吸灯、闪烁、超时、慢任务周期 |
| 注意 | 不适合 FOC 等 μs 级时序；长时间关中断会导致计时不准 |
