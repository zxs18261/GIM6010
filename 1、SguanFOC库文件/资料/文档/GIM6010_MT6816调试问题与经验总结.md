## 1. 硬件与软件架构

### 1.1 引脚

| 信号 | MCU | 说明 |
|------|-----|------|
| CSN | **PA15** | GPIO 软片选，空闲必须为高 |
| SCK | PB3 | SPI3_SCK |
| MISO | PB4 | SPI3_MISO |
| MOSI | PB5 | SPI3_MOSI |

### 1.2 软件分层

```
SguanFOC
  User_Encoder_ReadRad()     ← 返回电机轴机械角 [rad] 0~2π
        ↓
BSP_MT6816
  GetMechRad / Update        ← SPI 读角、电角度、减速比换算、速度
        ↓
HAL SPI3 + PA15 CSN
```

相关文件：

| 文件 | 作用 |
|------|------|
| `BSP/BSP_MT6816.c` `.h` | 驱动：读角、校验、角速度、输出轴换算 |
| `SguanFOC/UserData_Function.h` | `User_Encoder_ReadRad` / `User_InitialInit` 中 Init |
| `SguanFOC/UserData_UserControl.h` | VOFA 通道挂接机械角 |
| `Core/Src/spi.c` | CubeMX SPI3；USER CODE 内降波特率 |
| `Core/Src/gpio.c` | MT6816_CSN 默认高 |

### 1.3 量纲约定（本工程）

| 名称 | 含义 |
|------|------|
| 机械角 `mech_*` | 编码器侧 = **电机轴** |
| 电角度 `elec_*` | `mech × 极对数(14)`，归一化 0~2π |
| 输出轴 `shaft_*` | `mech / 减速比(8)` |
| `User_Encoder_ReadRad()` | 电机轴机械角 **rad** |

## 3. 遇到的问题与解决

### 问题 A：CubeMX SPI3 默认配置不符合 MT6816

**现象**

- 读数全 0、校验失败、角度乱跳或不更新  

**原因**

| 参数 | 错误默认 | 正确值 |
|------|----------|--------|
| Data Size | 4 bit | **16 bit** |
| CPOL / CPHA | Mode 0 | **Mode 3（High + 2Edge）** |
| Prescaler | /4 ≈ 42.5 MHz | **/16 或 /32**（≤15.6 MHz） |
| NSS Pulse | Enable | **Disable** |

**解决**

1. CubeMX 按上表修改并 Generate Code  
2. `BSP_MT6816_Init()` 内再次重配 Mode3/16bit（与参考工程一致，双保险）  
3. `spi.c` USER CODE 中将 Prescaler 强制为 `/32`（防止 CubeMX 仍为 `/4`）

---

### 问题 B：CSN 上电默认拉低

**现象**

- SPI 总线异常、偶发读失败  

**原因**

- 原 `gpio.c` 将 `MT6816_CSN` 初始为 `GPIO_PIN_RESET`  
- MT6816 要求空闲时 CSN = **高**  

**解决**

- CubeMX：PA15 Output Level = **High**，Speed = Very High  
- `BSP_MT6816_Init()` 开头再次 `CSN = High`，并 `HAL_Delay(16)` 等待上电就绪  

---

### 问题 C：角度未接到 SguanFOC / VOFA 看不到变化

**现象**

- 驱动已写好，但库内角度为 0，VOFA 无机械角波形  

**原因**

1. `User_Encoder_ReadRad()` 仍返回 0，未调用 BSP  
2. 当前 `main` 跳过 FOC 校准（直接 `IDLE`），`User_InitialInit()` 不执行 → `BSP_MT6816_Init()` 未调用  
3. VOFA 只显示 `User_UserTX()` 的 `fdata[]`，未把机械角填入通道  

**解决**

```c
// UserData_Function.h
static inline float User_Encoder_ReadRad(void){
    return BSP_MT6816_GetMechRad();
}

// User_InitialInit() 内
BSP_MT6816_Init();

// main.c（跳过校准时必须额外调用）
BSP_MT6816_Init();

// User_UserTX() — VOFA
float mech_rad = BSP_MT6816_GetMechRad();
Sguan.TXdata.fdata[9]  = mech_rad;                 // rad
Sguan.TXdata.fdata[10] = mech_rad * 57.2957795f;   // deg
```

---

### 问题 D：灯灭 + VOFA 全无（整机卡死）——与编码器调试叠加出现

**现象**

- 改 CubeMX / 烧录后，RGB 不亮，串口也无数据  

**原因（非 MT6816 本身）**

- CubeMX 重生成删除了 `DMA1_Channel3_IRQHandler`（RGB/WS2812 用）  
- DMA 完成进默认中断死循环 → 主循环停 → 编码器/VOFA 一并“假死”  

**解决**

- 在 `stm32g4xx_it.c` 的 `USER CODE BEGIN 1` 恢复：

```c
void DMA1_Channel3_IRQHandler(void)
{
    BSP_RGB_DmaIRQHandler();
}
```

- **每次 CubeMX Generate 后检查该函数是否还在**

---

### 问题 E：SPI 时钟仍然过快（CubeMX 只改了 Mode/位数）

**现象**

- 部分板子偶发奇偶校验失败（`BSP_MT6816_ERR_PARITY`）  

**原因**

- Prescaler 仍为 `/4`（约 42.5 MHz），超过 MT6816 SCK 规格  

**解决**

- CubeMX 改为 `/32` 或 `/16`  
- 代码侧 `BSP_MT6816_Init` + `spi.c` USER CODE 已降为 `/32`

## 4. CubeMX 必改项清单

打开 `GIM6010_V0.0.ioc` → SPI3 / PA15：

| 配置项 | 目标值 |
|--------|--------|
| SPI3 Data Size | **16 Bits** |
| Clock Polarity | **High** |
| Clock Phase | **2 Edge** |
| Baud Rate Prescaler | **/32**（或 /16） |
| NSS | Soft |
| NSS Pulse | **Disable** |
| PA15 | GPIO Output，标签 `MT6816_CSN` |
| PA15 默认电平 | **High** |
| PA15 Speed | Very High（推荐） |

引脚复用（一般已正确）：

- PB3/4/5 → SPI3 SCK/MISO/MOSI  

不必为 SPI3 开 DMA/中断（当前阻塞传输即可）。

## 5. 软件对接要点

### 5.1 初始化顺序

```
MX_GPIO_Init();
MX_SPI3_Init();          // 含 USER CODE 降速
...
BSP_MT6816_Init();       // Mode3/16bit、CSN 高、延时 16ms、预读
```

### 5.2 给 FOC 用

```c
static inline float User_Encoder_ReadRad(void){
    return BSP_MT6816_GetMechRad();  // 电机轴 [rad]
}
```

### 5.3 完整数据（速度/电角度/输出轴）

周期调用（如 1 kHz）：

```c
BSP_MT6816_Data_t enc;
BSP_MT6816_Update(&enc);
// enc.elec_rad, enc.mech_omega_rpm, enc.shaft_omega_rad_s ...
```

### 5.4 方向

转轴与电机正方向相反时：

```c
BSP_MT6816_SetInvert(1);
```

## 6. VOFA 观察方法

| 项 | 设置 |
|----|------|
| 协议 | JustFloat |
| 波特率 | **921600** |
| 通道数 | 21 |

当前机械角映射（`User_UserTX`）：

| 通道 | 内容 |
|:----:|------|
| Ch14 | MT6816 单圈机械角 [rad] 0~2π |
| Ch16 | MT6816 单圈机械角 [deg] 0~360 |

验收：慢转电机轴，Ch9/Ch10 连续变化；一圈对应约 6.28 rad / 360°。

## 7. 推荐调试顺序

```
1. CubeMX：Mode3 + 16bit + CSN 高 + Prescaler/32
2. 确认 DMA1_Channel3_IRQHandler 仍在（避免整机卡死）
3. 编译烧录，灯呼吸正常、VOFA 有基础通道
4. BSP_MT6816_Init + User_Encoder_ReadRad 对接
5. VOFA Ch9/Ch10 看机械角随转轴变化
6. 必要时 SetInvert 校正方向
7. 再接入 FOC 校准（status = UNINITIALIZED）与电流环
```

---

## 8. 注意事项（防再踩坑）

1. **CubeMX 重生成**后检查：  
   - SPI3 是否仍是 Mode3/16bit、Prescaler 是否又变回 `/4`  
   - `DMA1_Channel3_IRQHandler`（RGB）是否还在  
2. 跳过 FOC 校准时，务必在 `main` 里单独调用 `BSP_MT6816_Init()`。  
3. 当前源码与 `.ioc` 的 VOFA 波特率均为 **921600**，上位机必须保持一致。
4. `User_Encoder_ReadRad` 给的是**电机轴机械角**；电角度由库内部再乘极对数，勿在接口里重复乘 14。  
5. 读失败时 `GetMechRad()` 返回上次有效值，VOFA 可能“卡住”一小段，可结合 `BSP_MT6816_Update` 的 `status` 排查。  
6. 无磁报警（`ERR_NO_MAGNET`）：检查磁铁安装距离/对心。
