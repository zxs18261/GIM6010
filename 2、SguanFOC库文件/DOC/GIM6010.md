## 4. 功率级、PWM 与安全关断

| 项目 | 参数 | 来源 |
|------|------|------|
| 额定母线电压 | 24 V；当前交付未验证且不允许按 48V 上电 | 24V 电机 + 当前 ADC 量程边界 |
| MOS 管 | VS1804GPH ×6（Q1/Q3/Q7 上管，Q2/Q4/Q13 下管） | 用户需求+网表（PDFN-8） |
| 栅极驱动器 | FD6288Q（U2，QFN-24），三分立自举（D1/D2/D3 + C8/C10/C11）；具体料号仍须以 BOM 与实物复核 | 原理图 PDF + 随附 FD6288 数据手册 |
| PWM 定时器 | TIM1，中心对齐模式 1，PSC=0，**ARR=4249** → **20 kHz** | ioc |
| 死区 | ioc `DeadTime=9`，tDTS=2/170MHz → **约 106 ns**（用户要求 200 ns 时改为 DT=17，待确认是否需要） | ioc 计算 |
| PWM 极性 | `PWM_Dir = -1`（高低电平对应经实测确定） | 旧工程实测 |
| MOE 安全关断 | 显式使能；停机/故障使用 `__HAL_TIM_MOE_DISABLE_UNCONDITIONALLY` 或直接清 BDTR.MOE；Break 未启用（ioc BreakState=DISABLE，后续可启用 BRK 输入） | ioc + 源码 |
| ADC 触发 | TIM1_CC4（PWM2 模式，CCR=ARR-40，**峰值前（下溢附近）触发** → 采样下桥臂电流） | ioc + 旧工程实测 |

> **安全关断路径**：显式停机、通信接收错误/队列溢出、ADC 注入链连续 5 ms 无心跳、20 kHz 电流环连续 3 个周期达到或超过 50 µs、SguanFOC 故障态以及 CPU Fault 均无条件清 TIM1 MOE，使三相桥进入高阻；普通 HAL `__HAL_TIM_MOE_DISABLE` 会因通道仍启用而拒绝清 MOE，本工程禁止将它用于安全停机。连续超期策略只在校准及正常控制状态内累计，恢复后必须重新连续累计 3 次。硬件 Break 尚未启用，仍需后续实机改版验证。

## 5. 电流、母线电压与温度采样

### 5.1 相电流采样（下桥臂双电阻 + INA181A2）

```
V相下管(Q2) ── R14(5mΩ) ──┐
W相下管(Q13) ─ R16(5mΩ) ─┼── IBUS+ ── R2(5mΩ) ── PGND
U相下管(Q4) ──────────────┘            │
                                       R17(0Ω) ── AGND（单点连接）

U15(INA181A2): IN+ = IV+(R14压降上端)  IN- = IBUS+  → ADC1_IN12 (V相电流)
U19(INA181A2): IN+ = IW+(R16压降上端)  IN- = IBUS+  → ADC1_IN15 (W相电流)
U16(INA181A2): IN+ = IBUS+             IN- = PGND   → ADC2_IN12 (母线电流)
基准 1.65V(U18) → 双向电流，ADC 中点 = 2048
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样电阻 | 5 mΩ（R14/R16） | R1206 |
| 放大器 | INA181A2，**增益 ×20** | 旧工程实测采用 |
| ADC 量程换算 | `I = (ADC-2048)/4096 × 3.3V / (20×0.005Ω)` ≈ (ADC-2048)×0.00806 A | 库自动按 `Amplifier×Sampling_Rs` 计算 |
| 电流通道 | `Current_Num = 2`（BC 相 = IV+IW） | 库定义 0=AB,1=AC,2=BC |
| U 相电流 | 由 `Ia+Ib+Ic=0` 软件重构 | 库内部完成 |

### 5.2 母线电压采样（ADC1_IN14）

分压网络：`VBUS ── R20(30kΩ) ──┬── ADC1_IN14 ── R19(3kΩ) ── AGND`

- **分压比 1/11**：`VBUS = ADC/4096 × 3.3 × 11`
- ⚠️ **硬件量程限制**：ADC 3.3V 满量程对应母线约 **36.3 V**；48V 母线会使 ADC 节点理论上升至约 4.36V，已经超出当前采样链可测范围，禁止据此直接接入 48V。
- 软件阈值按既有配置为 **过压 50V / 欠压 10V**；驱动从约 35.45V（ADC 码 4000）起按过量程失效关断，为器差和噪声留出裕量。此时保护值和 Ch12 会显示 1000V 哨兵（不是实际物理电压），只能表达“已接近或超过量程边界”；若需 50V 定量检测必须修改分压网络并重新标定。

### 5.3 温度采样（双路 NTC 独立保护）

| 通道 | 引脚 | 位置 | 规格 | 过温阈值 | 故障策略 |
|------|------|------|------|----------|----------|
| 板载 NTC（位号 NTC2） | PA2 / ADC1_IN3 | **MOS 管旁**（板内焊接） | 3950 / 10kΩ / 0603，上拉 R3=10k→3.3V | **100 ℃**（用户要求） | 开路/短路 → 等效 **+120 ℃**（fail-safe 直接过温锁定） |
| 电机 NTC（外接 P1 焊盘） | PA3 / ADC1_IN4 | **电机绕组内部**（经连接器外接） | 暂按 3950/10k 假定（⚠️ 厂家未给规格，待确认），上拉 R4=10k→3.3V | **80 ℃**（电机额定工作温度上限，规格书 −20~+80℃） | 开路/短路/**未接** → **通道旁路**（不参与保护，台架可不接） |

- 换算（B 常数法，`T0=298.15K`，两路独立 B 值/R25 宏）：
  `R_ntc = 10k × Vadc/(3.3−Vadc)`；`T[K] = 1 / (1/298.15 + ln(R_ntc/R25)/B)`
- **库单比较点归一化**：SguanFOC 库只有一个 `Temp_MAX` 比较点 → `BSP_ADC_GetTemp()` 返回严重度归一化值：
  `severity = max( T_board×100/100 , T_motor×100/80 )`，库 `Temp_MAX=100` 时**任一通道达到自身阈值即触发过温锁定**
- 当前 24 通道 VOFA 帧不再直接显示两路物理温度；温度保护仍在运行。需要观测温度时应在受控调试固件中另加诊断通道，不能把当前 Ch21/Ch22（d/q 电流控制器输出）误当温度。
- ⚠️ 电机 NTC 实际 B 值/阻值拿到厂家规格后改 `BSP_ADC.h` 中 `BSP_ADC_NTC_MOTOR_*` 宏

### 5.4 采样调度

| 信号 | 通道 | 触发 | 频率 | 用途 |
|------|------|------|------|------|
| IV / IW / VBUS | ADC1 注入 Rank1-3 | TIM1_CC4 硬件触发 | 20 kHz | 电流环 + VBUS 快速监视 |

## 7. 编码器与位置反馈

| 项目 | 配置 |
|------|------|
| 型号 | MT6816（磁编码器，安装在**电机转子轴**上，非减速器输出轴） |
| 接口 | SPI3（Mode3 CPOL=1/CPHA=2Edge，16bit 帧，5.3125 Mbps），CS = PA15 软件控制，经 U3 电平转换接 CN47 外接口 |
| 类型 | **绝对式、单圈** |
| 分辨率 | **14 bit = 16384 CPR**（ANGLE 寄存器有效位，手册确认） |
| 采样方式 | 主循环调用 `BSP_MT6816_PollBlocking()`，以 HAL tick 门控为约 **1 kHz**；每次阻塞完成 SPI 双帧（命令 0x3000/0x3100 + 数据回读），带奇偶校验 + 无磁检测 |
| 无第二编码器 | 输出轴位置 = 转子位置 ÷ 8（软件折算） |
| 数据缓存 | 阻塞读取完成后发布快照（角度/速度/多圈计数），**20 kHz 电流环 ISR 只读缓存，绝不轮询 SPI**；旧 DMA 请求/服务 API 仅保留为停用实验路径 |

> BSP 层（`BSP/BSP_MT6816.c`）提供 `mech_rad`（转子单圈 0~2π）、`mech_cont_rad`（连续角）、`elec_rad`（电角度）、`mech_omega_rpm`（转子 rpm）、`shaft_*`（输出轴折算量）全套接口，含 DWT 时戳与失效超时检测。活动路径是主循环约 1 kHz 阻塞读取后发布缓存，不得依据保留的 DMA API 注释恢复 ISR 投递。

## 8. 三种角度、方向与零位约定

### 8.1 三种角度定义

| 角度 | 符号 | 定义 | 来源 |
|------|------|------|------|
| 机械角（转子） | `Real_Rad` | MT6816 单圈原始角，**0~2π**，以 **MT6816 增大方向为正** | 编码器直读 |
| 机械角（连续/多圈） | `Real_Pos` | 机械角累计圈数展开，PLL 平滑 | 库 PLL |
| 电角度 | `Real_Erad` | `机械角 × 极对数(14)`，归一化 0~2π，供 Park/SVPWM | 库计算 |

- **一切以转子机械角度（MT6816 值）为准**：判断电机正/反转、判断电角度方向、判断零位。
- 单圈范围统一 **0~2π**；`Real_Pos` 多圈连续。
- 输出轴角度 = 转子角 / 8（仅用于上位机显示与关节层面命令，控制环内部始终用转子角）。

### 8.2 方向约定与相序校准流程

**正方向定义：MT6816 读数增大的方向 = 关节正方向。**

上电校准流程（首次带载验证时执行，流程写入 §10 应用状态机 CALIBRATE 态）：

1. 上电读 MT6816 原始角 → 记录 `enc_start`
2. 以小 Uq 开环拖动电机正转（`Motor_Dir=+1`）
3. 若 `enc_end > enc_start`（增加）→ **相序正确**，`Motor_Dir=+1`、`Encoder_Dir` 保持
4. 若 `enc_end < enc_start`（减少）→ **三相焊反**：物理调换任意两相线，或软件置 `Motor_Dir=-1`（临时），最终以硬件调线为准
5. 电流方向同理验证：正 Iq 应产生正转矩（编码器读数增大），否则翻转 `Current_Dir0/1`
6. 结果写入 `UserData_Motor.h` 并记录到本文档 §15 台架记录

### 8.3 电角度零位（编码器-转子对齐）

- 库 INITIALIZING/CALIBRATING 流程执行：经用户层缩放后的 `Ud = 0.04×VBUS` 拉 d 轴 → 保持 1200 ms → 采样 MT6816 角为 `Pos_offset` → 撤压并等待 800 ms
- `Real_Erad = (mech_rad − Pos_offset) × 14`，软件自动完成
- 零位值断电丢失（无 Flash 保存），每次上电重新对齐（绝对编码器使对齐过程确定性可重复）

## 9. 控制架构与中断时基

### 9.1 控制环结构（SguanFOC 三环）

```
主循环：BSP_MT6816_PollBlocking() 约1kHz → 发布角度/速度缓存
                               │
┌──────────────── 20 kHz（ADC 注入完成 ISR）──────────────────────────┐
│ 读编码器缓存 → PLL/角度；Clarke/Park → Id/Iq                         │
│ 电流环 PI(D/Q) 每周期执行 → Ud/Uq → Park逆 → SVPWM → TIM1 CCR       │
│ 速度环每 Response=20 周期执行一次：约 1 kHz                          │
│ 位置环每 Response²=400 周期执行一次：约 50 Hz                         │
└────────────────────────────────────────────────────────────────────┘
TIM2 ISR（1 kHz）：状态机、保护和 ADC High_Loop 心跳监视
主循环：VOFA JustFloat 发送（500 Hz）/ FDCAN / RGB / UART 命令解析 / 慢 ADC（100 Hz）
```

### 9.2 中断优先级（NVIC，ioc 已定）

| 优先级 | 中断 | 功能 | 频率 |
|--------|------|------|------|
| 0 | ADC1_2_IRQn | 电流环 High_Loop | 20 kHz |
| 2 | TIM2_IRQn | Low_Loop（状态机、保护、ADC 心跳监视） | 1 kHz |
| 3 | USART1、DMA1 | 串口 VOFA 收发 | 500 Hz/921600bps |
| 0(未启) | TIM1_BRK 等 | 预留刹车保护 | — |

> TIM2 的 `Low_Loop` 负责状态机和保护，不直接执行速度/位置控制器。SPI3/DMA2 中断和旧异步 API 仍保留在工程中，但当前活动采样路径不投递 DMA 请求。

### 9.3 环路频率分配（库 Response=20 分频机制）

| 环 | 频率 | 驱动 |
|----|------|------|
| 电流环 | 20 kHz | ADC1 注入完成回调 |
| 编码器采样 | 约 1 kHz | 主循环 `BSP_MT6816_PollBlocking()`，HAL tick 自限速 |
| 速度环 | 1 kHz | 20kHz/Response(20) |
| 位置环 | 50 Hz | 20kHz/Response²(400) |
| 状态机+保护 | 1 kHz | TIM2 ISR |
| VOFA 上报 | 500 Hz | 主循环节拍 |

### 10.2 FOC 内核状态机（库内置，`Sguan_MotorStatus.h`，禁止修改）

| 编号 | 状态 | 含义 | 退出 |
|------|------|------|------|
| 0x00 | STANDBY | 待机（未初始化） | 解锁信号→0x01 |
| 0x01 | UNINITIALIZED | 等待初始化触发 | 自动→0x02 |
| 0x02 | INITIALIZING | 参数加载、外设启动、**编码器零位对齐** | 自动→0x03 |
| 0x03 | CALIBRATING | 校准（SVPWM 可用，转子校正） | 自动→0x04 |
| 0x04 | IDLE | 空闲（MOE 关闭，高阻等待目标） | 有效运动目标→运行态；模式0～2近零保持高阻，位置 `AO=0?` 也可有效 |
| 0x05/0x06 | TORQUE_INC/DEC | 力矩增大/减小中（电流模式） | 稳态→0x07 |
| 0x07 | TORQUE_CONTROL | 力矩保持（电流模式稳态） | — |
| 0x08/0x09 | ACC/DEC | 加/减速中（速度模式） | 稳态→0x0A |
| 0x0A | CONST_SPEED | 恒速（速度模式稳态） | — |
| 0x0B/0x0C | POSITION_INC/DEC | 位置增/减中（**位置模式**） | 到位→0x0D |
| 0x0D | POSITION_HOLD | 位置保持（**位置模式稳态**） | — |
| 0x0E | OVERVOLTAGE | 过压（**锁定**） | 手动解除→0x00 |
| 0x0F | UNDERVOLTAGE | 欠压（**锁定**） | 手动解除→0x00 |
| 0x10 | OVERTEMPERATURE | 过温>100℃（**锁定**） | 手动解除→0x00 |
| 0x11 | UNDERTEMPERATURE | 低温（锁定） | 手动解除→0x00 |
| 0x12 | OVERCURRENT | 过流（当前实现锁定并立即关 PWM） | 条件恢复后手动 `CO=1?` |
| 0x13 | ENCODER_ERROR | 编码器故障（锁定） | 手动解除→0x00 |
| 0x14 | SENSOR_ERROR | 传感器故障（锁定） | 手动解除→0x00 |
| 0x15 | PWM_CALC_FAULT | PWM 计算错误/连续 3 个 50 µs 周期超期（锁定） | 手动解除→0x00 |
| 0x16 | EMERGENCY_STOP | 急停（立即关 PWM，锁定） | 手动解除→0x00 |
| 0x17 | DISABLED | 软失能（缓慢停止） | 自动→0x00 |

**状态转移图（运行主线）**：

```
0x00 STANDBY ─解锁─► 0x01 ─自动─► 0x02 INITIALIZING(对齐Ud) ─► 0x03 CALIBRATING ─► 0x04 IDLE
                                                                    │
             ┌──────────────────────────────────────────────────────┤
             ▼                                                      ▼
模式=电流: 0x05/0x06 ⇄ 0x07        模式=速度: 0x08/0x09 ⇄ 0x0A     模式=位置(本期): 0x0B/0x0C → 0x0D
             │                                                      │
             └─────────── 任意运行态 ──► 故障态 0x0E~0x17 ◄──────────┘
                              故障态 ──条件消失后显式 CO=1? ──► 0x01（重新初始化/对齐）
```

### 10.3 应用层关节状态机（`APP/app_joint.c`，新增）

| 状态 | LED（WS2812B） | 进入条件 | 动作 |
|------|---------------|----------|------|
| APP_INIT | 白色呼吸 | 上电 | 外设自检、FDCAN 上线、等待 500ms |
| APP_STANDBY | 绿色慢闪 | APP_INIT 完成 | **不自动使能闭环**（防首次闭环方向符号未知导致过流），等串口 `CO=1?` 或 CAN 使能 |
| APP_IDLE | 绿色呼吸 | FOC 0x04 | MOE 关闭，等待当前模式的显式目标 |
| APP_CALIBRATING | 黄色闪烁 | FOC 0x02~0x03 | 观察对齐过程（可扩展相序自检 §8.2） |
| APP_RUNNING | 青色呼吸 | FOC ≥0x04 且收到目标 | 按当前模式执行目标；位置命令与 Ch9 反馈均为电机轴 rad |
| APP_FAULT | 红色快闪 | FOC 故障态(0x0E~0x17) | 记录故障码，等待清除命令 |
| APP_DISABLED | 蓝色慢闪 | 收到失能命令 | 置 DISABLED 信号，FOC 软停 |

应用层命令由串口 VOFA 或 FDCAN 统一仲裁。串口使用 `BO=0..3?`、`AO=<有限十进制>?`、`VO=<有限十进制>?`、`CO=0/1?`；FDCAN 使用 §12.2 的模式/使能/停机位。位置零点只由显式初始化后的对齐建立，CAN bit5 保留且必须写 0。

## 12. 串口与 FDCAN 协议

### 12.1 串口 VOFA（调试通道，USART1 921600）

**下行（PC→板）SguanFOC 原生格式 `XX=数值?`**：

| 命令 | 功能 | 单位 |
|------|------|------|
| `BO=3?` | 切模式：0开环/1电流/2速度/**3位置** | — |
| `AO=1.57?` | 目标值（位置模式=目标位置） | rad（电机轴） |
| `VO=30?` | 辅助目标（开环=输出轴速度） | rad/s |
| `CO=0?` / `CO=1?` | 精确 `0`=任意时刻停机清零；精确 `1` 在 Ch0=1～3 时忽略，否则先关桥清目标，STANDBY/可清故障态重新初始化、IDLE/运行态只回 IDLE；其他数值拒绝 | — |

`BO`/`CO` 必须采用上表所示的单个 ASCII 数字格式；小数、正负号和科学计数法只适用于 `AO`/`VO` 中允许的有限十进制值。

| 1 | 输出轴实测速度 | rpm | 13 | 实际电角度 | rad |
| 2 | 输出轴目标速度 | rpm | 14 | MT6816 单圈机械角 | rad |
| 3/4 | Id / Iq | A | 15/16 | IV / IW 原始 ADC（故障冻结） | count |
| 5 | U 相 CCR | count | 17/18 | IV / IW 偏置（故障冻结） | count |

| 7 | Uq | V | 21/22 | d / q 电流控制器输出（故障冻结） | V |
| 8 | Ia | A | 23 | Iq 目标（故障冻结） | A |

### 12.2 FDCAN（多轴总线，1 Mbps 经典帧，本期实现基础子集）

| 帧 | ID 规则 | DLC | 载荷 | 方向 |
|----|---------|-----|------|------|
| 位置命令 | `0x100+节点号` | 8 | `int32 位置µrad(输出轴) + int16 速度rpm限幅 + uint16 模式/使能位` | 主→从 |
| 状态遥测 | `0x200+节点号` | 8 | `int32 位置µrad + int16 转速rpm + uint16 状态/故障码` | 从→主(500Hz) |
| 广播同步 | `0x7FF` | 0 | — | 主→从(预留) |

- 节点号：拨码/Flash 参数（本期 `CANFD_NODE_ID` 编译期宏，默认 1）
- 波特率 1Mbps：在 `fdcan.c [USER FDCAN1_Init 1]` 覆盖（170M/(10×(1+12+4))，采样点 76.5%）
- 连续位置超过 int32 微弧度范围（约 +2147.483647/-2147.483648 rad）时遥测饱和、不回绕；转速同样按 int16 rpm 饱和，非有限位置/速度编码为 0 并保留状态字。

### 17.1 上电与显式初始化时序（必须结合上位机状态）

```
上电 ─► 白色呼吸(500ms) ─► 绿色慢闪(STANDBY，MOE关闭)
     ─► 发送 BO=<模式>?、CO=1? ─► 黄色闪烁(初始化/对齐) ─► Ch0=4、绿色呼吸(IDLE，MOE仍关闭)
```

- **绿色慢闪只表示 STANDBY；绿色呼吸只表示 IDLE。两者都不代表位置环已经带电保持。**
- 黄色闪烁/对齐只会在显式 `CO=1?` 后出现；对齐期间不要触碰电机轴，也不要重复发送启动命令
- ❌ 红色快闪 = 故障锁定，查 §17.5 故障码表

### 17.2 STANDBY 静态体检（不发运动命令）

| 检查项 | VOFA 通道 | 正常值 | 异常处理 |
|--------|-----------|--------|----------|
| 母线电压 | Ch12 | ≈ 电源电压（÷11 换算） | 偏差大 → 查 R19/R20 焊接；<10V 欠压锁定 |
| 编码器 | Ch14(rad) | **手转电机轴，数值在 0~2π 内连续变化并正确跨零** | 不变 → SPI 线/磁铁；跳变 → 干扰 |
| 高频环计数 | Ch6 | STANDBY 不要求 20kHz 递增；初始化后相邻 500Hz 帧增量约 40 | 初始化后冻结 → 查 ADC 触发/IRQ |
| 状态机 | Ch0 | 上电待命为 0 (STANDBY) | 未发 `CO=1?` 不应自动变为 1~4 |
| 功率桥 | 示波器/逻辑分析仪 | STANDBY 无门极脉冲、TIM1 MOE=0 | 有脉冲立即断电排查 |
