# GIM6010 FOC Safety Bring-Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成闭环首次上电前的电流通道一致性、D/Q 电压限幅、非法母线电压防护和初始化诊断。

**Architecture:** 保持 20 kHz ADC 注入高频环与主循环 MT6816 缓存边界不变；在进入 SVPWM 前统一检查 D/Q 指令和 VBUS；继续使用显式 MOE 关断。仅修改应用/FOC 用户层，不修改 CubeMX 外设生成逻辑。

**Tech Stack:** STM32G431、SguanFOC 3.0.1、Arm Compiler 5、Keil MDK、PowerShell 静态检查。

---

### Task 1: 核对现有整改并补齐最终安全门

**Files:**
- Modify: `SguanFOC v3.0.1/SguanFOC.c`
- Modify: `SguanFOC v3.0.1/UserData_Config.h`

- [ ] 确保闭环 D/Q 指令在 SVPWM 前执行有限值检查和 0.30 V 保守限幅。
- [ ] 确保 VBUS 为零、负值、NaN 或 Inf 时不进行除法，直接清零输出并关闭功率桥。

### Task 2: 保持采样和诊断通道一致

- [ ] 确认控制、电流遥测、故障快照均使用 Rank1=IV、Rank2=IW。

### Task 4: 烧录后的分阶段台架验证

- [ ] 断开电机母线或使用限流低压电源上电，确认 Ch0=0、MOE 关闭。
- [ ] 选择 BO=1，发送 CO=1，确认 Ch0 依次为 1~3 后到 4。
- [ ] 发送 AO=0.01，确认电流、Ud/Uq 和母线均受限；异常立即 CO=0 并断电。
- [ ] 逐步验证方向、正负 Iq、速度和位置，不跨级调参。
