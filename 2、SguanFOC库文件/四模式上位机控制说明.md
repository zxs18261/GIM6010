# GIM6010 四模式上位机控制说明

本工程通过 USART1（921600、8N1）接收 ASCII 命令，通过 VOFA+ JustFloat 回传 24 路状态。控制命令可被 DMA 分片，也可在一次接收中连续发送；非法数字、NaN、Inf、指数写法、尾随字符和超长帧会被拒绝。

> 本次完成的是源码与工程静态整改，未自主构建、烧录或进行电机台架验证。首次上电必须限流，并核对编码器方向、相序、电流采样极性和闭环参数。

## 安全启动顺序

1. 上电后功率桥保持关闭，前 500 ms LED 为橙色呼吸（用于确认本版本程序已运行），随后进入待命。
2. 发送 `BO=<模式>?` 选择模式，模式只能是整数 0、1、2、3。
3. 在 Ch0=0 的 STANDBY（或故障条件已消失的锁存故障态）发送 `CO=1?`，开始电流偏置校准和转子对齐。校准期间不要触碰电机轴，也不要重复发送 `CO=1?`。
4. 等待遥测 Ch0 变为 4（IDLE）。在 Ch0=4 以前不要发送运动目标。
5. 发送当前模式对应的有效运动目标。模式 0～2 的近零目标保持高阻；位置模式的 `AO=0?` 是有效回零/保持目标，也可能打开功率桥。
6. 任意时刻发送 `CO=0?`，目标立即清零且 TIM1 主输出关闭。

运行中切换 `BO` 会先关闭功率桥、清除旧目标并返回 IDLE，必须再发送新模式目标，旧模式的命令不会直接带入新模式。

## 四种模式

下表“目标示例”均假定初次启动时已经按上一节完成 `BO=<模式>?`、`CO=1?`，并确认 Ch0=4；不得把选择、初始化和运动目标不等待地一次连发。已初始化后的模式切换会自行回到 Ch0=4，无需重新对齐，但仍必须发送新模式目标。

| BO | 模式 | 上位机目标 | 单位与范围 | Ch0=4 后的目标示例 |
|---:|---|---|---|---|
| 0 | 开环 | `VO` 设置输出轴转速；`AO` 设置 q 轴电压 | VO: rad/s，限幅 ±30.79；AO: V，限幅 ±0.35×VBUS | 先 `VO=1?`，再从 `AO=0.2?` 小步增加 |
| 1 | 转矩/电流闭环 | `AO` 设置 Iq | A，限幅 ±6.6 | 从 `AO=0.01?` 开始，稳定后再小步增加 |
| 2 | 速度闭环 | `AO` 设置输出轴转速 | rad/s，限幅 ±30.79 | 从 `AO=0.5?` 小步增加 |
| 3 | 位置闭环 | `AO` 设置电机轴连续机械角 | rad，可正、负及多圈，限幅 ±512 | 从 `AO=0.05?` 等零位附近小阶跃开始 |

模式 1 的 `AO` 是 Iq 电流目标，并不是 N·m。按当前资料，输出轴转矩可用 `Iq × 0.61 N·m/A` 粗略估算，但实际值还受效率、减速器和参数误差影响。模式 0 没有转矩闭环，`AO` 仅是电压给定，不能当作准确转矩。

位置目标当前沿用库内坐标，是电机轴连续角度；如上位机希望直接输入输出轴角度，应先乘减速比 8。比如输出轴 90° 对应命令 `AO=12.5664?`。不得把度数直接作为 `AO` 发送。

连续位置零点来自本次上电对齐；PLL 在四种模式中持续保留多圈坐标，因此从开环、转矩或速度模式切回位置模式不会主动清零圈数。

## 命令规则

- 帧格式固定为两个大写字母、等号、参数、问号，如 `AO=-0.2?`。
- `AO`/`VO` 支持 `+`、`-` 和小数，不支持科学计数法；`BO`/`CO` 只接受一个 ASCII 数字，`BO=1.0?`、`CO=+1?` 等写法会被拒绝。
- 多条命令可以连续发送，如 `BO=2?AO=1.5?`。
- `CO` 只接受精确的 `0` 或 `1`；其他数值全部拒绝，不能用阈值数值代替启停。
- Ch0 不在 1～3 时，`CO=1?` 会先关桥并清除全部旧目标：STANDBY 或允许清除的故障态进入重新初始化/对齐，IDLE 或运行态只回到 IDLE；随后必须重新发送目标。初始化/对齐（Ch0=1～3）进行中重复 `CO=1?` 会被忽略，不能把它当成停机；任意时刻可靠停机只使用 `CO=0?`。
- `CO=0?` 是停机，不是速度置零：它同时关闭功率桥，但不会清除已经锁存的硬件故障码。
- 运行中的 `AO=0?` 只清零当前模式目标；模式 0～2 可能保持零矢量和桥使能，不能当作高阻停机，可靠停机请发送 `CO=0?`。位置模式的 `AO=0?` 是有效的绝对位置目标。
- `VO` 只在模式 0 生效；其他模式发送 `VO` 不改变控制目标。
- 故障会锁存；`CO=1?` 只有在母线、温度、编码器等对应异常已经消失后才允许重新初始化，对齐前还会再次预检。

## 当前安全边界

- ADC 初始化采用“停止 TIM1 触发 → 停止注入/规则转换 → 校准 → 启动注入中断 → 再启 TIM1”的失败关闭顺序；任何 HAL 失败均保持 MOE=0 并锁存传感器故障。
- UART DMA 错误或接收队列溢出时会立即关桥，并同时丢弃排队数据与解析器中的残缺半帧；断裂前的 `CO=1` 前缀不能与后续字节重新拼成启动命令。
- TIM2 每 1 ms 检查 20 kHz ADC 注入回调计数；连续 5 ms 无更新会关闭功率桥并锁存传感器故障。该心跳只确认计数有增长，不证明实际频率始终为 20 kHz；若最高优先级 ADC ISR 永久卡死，TIM2 本身也可能无法运行，因此它不能替代独立硬件快速关断或硬件看门狗。
- 20 kHz 电流环以 50 µs 为单周期预算；仅在校准及正常控制状态内连续 3 个周期达到或超过预算时，才关闭功率桥并锁存 `PWM_CALC_FAULT`。偶发单次超期会计数但不会立即停机。当前 DWT 统计覆盖 `SguanFOC_High_Loop()` 主段，不含 HAL ADC IRQ 入口/出口及回调尾部开销；阈值和完整最坏执行时间仍需在目标固件及实机上测量确认。
- 电流偏置完成后，对齐阶段每个 ADC 周期都会检查两路实测相电流及重建的第三相；当前独立阈值为 3.0 A。该值只是首次低压、限流台架的保守起点，尚未针对本机采样噪声和实际对齐电流验证。
- 当前上位机控制集成只支持并复审了 float FOC 路径，`Open_Q31_Calculate` 由编译期检查强制保持为 0；不得解除该限制生成 Q31 固件。
- 四模式交付依赖 JustFloat 24 通道，`Open_Printf_Debug` 由编译期检查强制保持为 0；内部模式值若越出 0~3，不会自动降级到开环，而会清零 dq 给定、关闭功率桥并锁存 `PWM_CALC_FAULT`。
- 当前 TIM1 Break/Break2 未在工程中启用；板载栅极驱动器/功率级是否具备并已正确配置快速过流保护，必须按实际 U2 型号、原理图和实测结果核实。台架电源限流以及人工急停仍是首次上电必需条件，不得据此源码静态检查宣称已达到生产级安全。
- 母线 1/11 分压在约 36.3V 已到 ADC 满量程；从 ADC 码 4000（约 35.45V）起会被映射为 1000V 过量程哨兵并关断，避免配置为 50V 的阈值被饱和读数绕过并为器差/噪声留裕量。1000V 只表示超出可信量程，不是物理测量值；该策略不能精确测量高压，24V 电机台架不得使用旧文档中的 48V 供电说法。

## 台架验收清单

- 复位和待命状态确认 TIM1 MOE 为 0，无门极脉冲。
- 手转电机检查 MT6816 单圈角连续、跨零方向正确且无跳变。
- 空载、限流电源下先验证模式 0 的正负 VO 和小幅 AO。
- 模式 1 从 ±0.01 A 小阶跃开始，确认正 Iq 产生正方向转矩且电流闭环不发散，稳定后再逐步增至 0.02/0.05 A。
- 模式 2 从低速开始，确认正负速度、零速停稳和超限命令被钳位。
- 模式 3 从小角度开始，确认连续角坐标、方向、减速比和到位保持。
- 四种模式运行中逐一切换，确认切换瞬间 MOE 关闭、旧目标清零、新目标发送后才重新动作。
- 制造编码器异常、欠压/过压或急停条件，确认状态进入故障并关闭 PWM。
- 在限流电源下验证对齐电流正常且不误触发 3.0 A 软件阈值，再决定是否调整 `USER_ALIGN_CURRENT_LIMIT_A`；不得直接提高阈值绕过故障。
- 断开 ADC 注入触发或屏蔽 ADC IRQ，确认 5 ms 心跳超时进入传感器故障并关闭 MOE。
- 在调试固件中受控注入连续 3 次控制周期超期，确认进入 `PWM_CALC_FAULT` 并关闭 MOE；同时确认单次超期后紧跟正常周期不会误锁故障。

当前闭环最终 dq 电压限制仍采用保守台架值；在方向、采样极性和保护动作全部实测通过前，不要提高限制或带载运行。

## FDCAN 四模式目标（实验接口）

本轮四模式上位机验收主接口是 USART1/VOFA+。FDCAN 已接通滤波、中断、队列和四模式命令，但尚未实现主机心跳超时与 bus-off 后自动停机，只能在有人监护的台架联调中使用，不能作为无人值守控制口。

经典 CAN 命令帧 `0x100 + 节点号` 的 8 字节定义为：`int32 target + int16 speed_rpm + uint16 control`，均为小端。control 的 bit0=使能、bit1=清故障、bit2=停机、bit3..4=模式；bit5 及其余位保留，必须写 0。位置零点只由本次上电对齐建立。

- 模式 0：target=Uq[mV]，speed_rpm=输出轴转速。
- 模式 1：target=Iq[mA]，speed_rpm 忽略。
- 模式 2：target 写 0，speed_rpm=输出轴转速。
- 模式 3：target=输出轴位置[µrad]，speed_rpm 忽略。

带使能或清故障的帧只启动初始化；主机必须等待状态遥测为 4 后再发一帧目标。停机位优先级最高，同帧的使能和目标会被忽略。

CAN 遥测的位置字段受 int32 微弧度量程限制：输出轴连续位置超过约 +2147.483647 rad 或 -2147.483648 rad 时饱和，不回绕；速度字段同样按 int16 rpm 饱和。非有限位置/速度编码为 0，故障状态仍通过状态字报告。
