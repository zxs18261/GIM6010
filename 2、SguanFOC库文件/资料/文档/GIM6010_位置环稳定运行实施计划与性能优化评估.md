# GIM6010：位置环实施计划与性能优化评估（历史评估，含现行差异补注）

> 原始评估日期：2026-08-21；现行状态复核：2026-09-05。  
> 本文保留原始实施思路，但原文中“当前工程”的表述不再全部代表现行代码。现行上位机协议、四模式行为和安全边界以项目根目录 [`四模式上位机控制说明.md`](../../四模式上位机控制说明.md) 为准。  
> 现行源码已完成四模式与安全链路的静态整改；尚未执行 Keil 构建、烧录和电机台架验证。相序、方向、负载惯量和供电能力仍必须以限流台架测试为准。

## 1. 先给结论

2026-08-21 的基线工程只具备低风险开环验证所需的基本链路：

~~~text
开环角度积分 + Uq 给定
    -> 逆 Park / SVPWM
    -> TIM1 三相互补 PWM
    -> GIM6010 功率级
~~~

现行源码已经补齐开环、Iq 电流/转矩、速度、连续位置四种上位机模式，并将高频控制迁移到 20 kHz ADC 注入完成回调；这仍只代表静态实现完成，不代表闭环参数已经通过实机验证。

首次台架仍不能直接用大位置阶跃调 `Position.Kp`。应按本文第 5 节由内到外验收电流采样、方向、保护、电流环、速度环和位置环，否则可能出现抖动、失步、超调或保护停机。

建议遵循本文第 5 节的阶段顺序。每一阶段都有独立验收门槛，未通过时不要进入下一阶段。

## 2. 原始基线与现行控制架构

### 2.1 当前执行路径

现行 TIM1 产生约 20 kHz 三相 PWM，并通过 CH4 触发 ADC 注入采样。控制与安全任务划分如下：

~~~text
TIM1 / ADC1 注入完成回调（约 20 kHz）
  -> 锁存 IV、IW、VBUS 快速采样并执行过压关断
  -> SguanFOC_High_Loop()
      -> 读取最近 MT6816 有效缓存
      -> Clarke/Park、四模式控制、SVPWM
      -> 统计执行周期并在连续超期时关断

TIM2（1 kHz）
  -> 检查 20 kHz ADC 回调心跳
  -> SguanFOC_Low_Loop()：状态机与保护逻辑

主循环
  -> 解析 UART DMA 命令队列
  -> 最高 1 kHz 阻塞读取 MT6816 并发布缓存
  -> SguanFOC_main_Loop()、VOFA 数据打包/UART DMA、RGB 轮询
~~~

20 kHz FOC 路径和 VOFA 均不直接访问 SPI3。BSP 中保留的 SPI DMA request/service 代码当前没有接入活动调度；在解决曾出现的使能后采样失败并完成台架复核前，不应宣称编码器已按 4 kHz DMA 运行。

对应源码位置：

- 高频/低频回调与超期检查：`APP/app_callbacks.c`
- 主循环编码器轮询：`APP/app_joint.c`
- PWM 频率、ADC 触发与 TIM2 配置：`Core/Src/tim.c`、`Core/Src/adc.c`
- 控制主路径：`SguanFOC v3.0.1/SguanFOC.c`

### 2.2 当前位置环为何不适合追求快速响应

现行 `UserData_Config.h` 由 `USER_FOC_CONTROL_HZ=20000` 统一推导 `TIM_T=50 us`，High_Loop 由 ADC 注入完成回调按每个 PWM 周期执行一次。原始版本的 1 ms 调度与 100 us 参数周期不一致问题已经消除。

现行 `USER_CONTROL_RESPONSE=20`，按 20 kHz High_Loop 计算：

- 电流环：20 kHz
- 速度环：1 kHz
- 位置环：50 Hz

位置环 50 Hz 是首次闭环上电的保守静态配置；是否满足目标响应、是否需要提频，只能在内环稳定且有执行时间和波形证据后决定。

相关源码：

- 基准周期与 Response：`SguanFOC v3.0.1/UserData_Config.h`
- 参数装载：`SguanFOC v3.0.1/UserData_Parameter.h`
- 三环分频：`SguanFOC v3.0.1/SguanFOC.c`

## 3. 个人配置阶段必须处理的事项

以下项目按优先级排列。前四项应视为进入闭环前的必做项。

### 3.1 必做：统一控制周期

原始版本存在 1 ms 实际执行周期与 100 us 参数周期不一致的问题。现行版本已经统一为以下多速率任务：

- 电流环：20 kHz，跟随 TIM1/ADC 的 PWM 同步时刻执行。
- 编码器采样：主循环最高约 1 kHz 阻塞读取，20 kHz 电流环只读缓存。
- 速度环：1 kHz。
- 位置环：50 Hz，作为首次限流台架的保守起点。
- 保护与状态机：1 kHz。
- VOFA 常规遥测：500 Hz，DMA 忙时丢弃而不阻塞控制。

后续若恢复 2 至 5 kHz SPI DMA 编码器采样或提高位置环频率，必须重新测量执行时间和采样稳定性，不能只改宏定义。

### 3.2 必做：确认双电阻电流相序和电流方向

板卡硬件实际采样的是 V 相和 W 相：

- ADC1_IN12 / PB1：IV
- ADC1_IN15 / PB0：IW

现行 `UserData_Motor.h` 已统一为 `Current_Num=2`（BC，即 IV+IW）、`Current_Dir0=-1`、`Current_Dir1=-1`，放大倍数按 INA181A2 配为 20，采样电阻为 5 mΩ。两路极性来自 2026-08-31 的受限小电流台架观察，但仍需在目标硬件上复验，不能仅凭静态配置视为最终标定。

错误的相电流映射会导致：

- Id、Iq 的符号或幅值不正确；
- 过流判断失真；
- 电流环无法整定；
- 速度和位置环即使参数正确也会抖动或反向。

在低压、限流、空载条件下，应依次确认：

1. 三相 PWM 的逻辑相 U/V/W 与实际功率相一致。
2. 两路 ADC 零电流偏置正确，静止时 Ia、Ib、Ic 近似为零。
3. 小 Uq 开环转动时，估算相电流和实际转向一致。
4. 轻推转子时，编码器方向、机械速度符号和电角度变化方向一致。
5. 通过实际测试确定 Current_Num、Current_Dir0、Current_Dir1、Motor_Dir、PWM_Dir、Encoder_Dir 的最终组合，并记录到板级文档。

不要根据相线颜色或猜测固定这些参数。

### 3.3 必做：实现真实保护和安全关断

现行版本已经接入 VBUS 与双路温度采样、编码器新鲜度、ADC 心跳、控制超期、UART/CAN 停机和统一 MOE 关断；模式切换、停机和故障恢复会清空旧目标及控制器状态。ADC 过量程也会在 20 kHz 回调现场直接锁存过压并关桥。

仍未完成的安全项是目标板上的标定与故障注入验证，以及独立硬件快速关断。TIM1 Break/Break2 当前未启用；板载栅极驱动器/功率级是否具备并已正确配置快速过流保护，必须按实际 U2 型号、原理图和实测结果核实。软件检查不能替代经确认的硬件保护、台架电源限流和人工急停。

### 3.4 必做：建立位置和速度的唯一单位约定

现行 `User_Encoder_ReadRad` 返回预测后的电机轴单圈机械角缓存，库内 PLL 将其展开为电机轴连续机械位置。UART 位置模式的 `AO` 直接使用电机轴连续弧度；若上位机给定输出轴角度，需要换算：

~~~text
电机轴目标角 = 输出轴目标角 × 8
电机轴速度 = 输出轴速度 × 8
~~~

现行文档采用以下命名：

- motor_rad：电机轴机械弧度
- shaft_rad：减速输出轴机械弧度
- elec_rad：电角度
- position_cmd_motor_rad：UART 上位机位置命令

位置零点来自最近一次成功初始化/对齐；即使没有断电，`CO=0?` 后再次由 STANDBY 执行 `CO=1?` 也会重建零点。`AO` 是该局部连续坐标中的绝对目标，不是相对当前位置的增量；系统没有机械回零开关或掉电多圈保存，因此它也不是跨重启绝对位置。

### 3.5 建议：用 PI 速度环完成首版闭环

当前 Open_PI_Control = 0，速度环使用 STA。STA 可用于后续性能优化，但首次建立三环稳定性时，常规 PI 的可解释性和调参路径更清晰。

推荐顺序：

1. 首版电流环使用 PI。
2. 首版速度环使用 PI。
3. 位置环先使用 P 或低增益 PD，位置积分保持为 0。
4. 只有在内环稳定、摩擦/负载特性已知后，再评估 STA、MTPA、弱磁等附加功能。

## 4. 最终推荐的任务划分

### 4.1 目标架构

~~~text
ADC 注入转换完成 / TIM1 同步事件（20 kHz）
  -> 读取本周期电流采样
  -> 电角度预测或读取缓存
  -> Clarke / Park
  -> Id/Iq PI
  -> SVPWM 占空比更新

编码器任务（2 至 5 kHz）
  -> SPI DMA 或受时限的底层轮询
  -> 校验、无磁检测、连续圈数展开
  -> 发布带时间戳的角度、速度、有效性缓存

速度任务（1 kHz）
  -> 读取编码器缓存
  -> 速度 PI
  -> 输出 Iq_ref，并进行限幅

位置任务（250 至 500 Hz）
  -> 位置目标轨迹生成（速度/加速度限制）
  -> 位置 P/PD
  -> 输出 speed_ref，并进行限幅

低优先级任务
  -> VBUS / 温度、状态机、VOFA、RGB、命令解析
~~~

### 4.2 不应放入电流环的内容

下列内容不应继续放进最终的 20 kHz 电流环：

- HAL_SPI_TransmitReceive 阻塞式读取 MT6816；
- HAL_Delay；
- UART 发送或字符串解析；
- RGB DMA 启动；
- 状态机中的复杂处理；
- 浮点格式化、日志输出。

现行 High_Loop 只读取 MT6816 缓存，不执行阻塞 SPI。5 ms SPI 超时只存在于初始化和主循环的阻塞读取路径；它不会直接阻塞 20 kHz ADC ISR，但可能拖慢主循环并使缓存超过新鲜度阈值，届时安全状态机会关闭 PWM。

## 5. 历史分阶段实施计划

本节是原始推进顺序，用于解释为什么必须由内到外验收。已经完成的源码项不等于实机门槛已通过；具体操作命令以现行四模式说明为准。

### 阶段 0：可重复构建与测量基线

目标：确保“当前源代码”和“实际烧录固件”是同一版本。

执行项：

1. 解决 Keil 当前设备包/Toolchain 不支持 STM32G431CBTx 的构建问题。
2. 成功全量编译并保存 build log、axf、hex 的时间戳。
3. 固定当前开环最小测试条件：供电电压、电流限制、是否空载、串口波特率。
4. 在 VOFA 记录 Ch0、Ch6、Ch7、Ch11、Ch13、Ch14、Ch17。

验收：

- 构建为 0 error、0 warning。
- 烧录版本可追溯到当前提交/工作区。
- 上电后完成校准，Ch0 进入 IDLE，Ch11 为开环模式。

### 阶段 1：安全链路和硬件接口验收

目标：在不追求性能前先确保失效时电机可控地停止。

执行项：

1. 接入 VBUS、温度、急停、编码器故障的真实输入。
2. 建立统一的 Motor_Disable 输出函数，明确关闭 MOE、清空 PWM、清零目标和 PID 积分。
3. 将 ADC、电流、母线和温度阈值设置为保守值。
4. 用限流电源验证开环对齐阶段不会触发供电保护。

验收：

- 拔掉编码器、模拟低母线、模拟过流时，PWM 在可测的短时间内关断。
- 故障解除后不会自动恢复到带扭矩状态。

### 阶段 2：ADC、电流相序、PWM 和编码器标定

目标：让测量坐标系与功率坐标系一致。

执行项：

1. 记录静止 ADC 原始值、偏置、换算后的两相/三相电流。
2. 用已知电流或外部表计校验电流增益，确认实际是 10 倍还是 20 倍。
3. 低 Uq 开环确认 PWM 相序和转向。
4. 完成编码器方向、机械零位、电角零位校验。
5. 确认 Current_Num 和三个方向符号，写入板级参数表。
6. 示波器确认 ADC 采样窗口避开开关尖峰。

验收：

- 静止时 Id/Iq 无明显漂移。
- 正负小电流的符号正确。
- 同一开环命令在连续上电后转向一致。
- 转子手动旋转一圈时，机械角、电角度、速度方向均符合预期。

### 阶段 3：实时架构重构

目标：将 1 kHz 演示控制改为可支撑伺服的多速率控制。

执行项：

1. 将电流环移到 TIM1/ADC 同步的 10 至 20 kHz 路径。
2. MT6816 改为独立缓存任务；电流环仅读取最新有效角度。
3. 统一每个控制器的离散周期，不再共用不匹配的 TIM_T。
4. 测量每个中断最大执行时间和抖动。
5. 将 UART、DMA、RGB 的中断优先级降至控制中断之下。

验收：

- 电流环执行时间有至少一半以上的周期余量。
- 编码器失败不会阻塞电流环。
- 控制周期与 PID/PLL/LPF 参数一致。

### 阶段 4：受控开环和相序确认

目标：建立可重复的、不会突然大幅加速的开环启动流程。

执行项：

1. 保留对齐阶段，但将对齐电压和时间参数化。
2. 以 V/f 限制配合速度斜坡，从低电角速度平滑升至目标值。
3. 默认命令使用低 Uq、低电角速度，禁止上电直接高 Uq。
4. 记录 Uq、电流、实际机械速度、编码器角。

验收：

- 低电压下可重复正反转。
- 电机不出现明显反冲、卡顿、异常发热。
- 电流不过限，编码器反馈方向正确。

### 阶段 5：电流环闭环

目标：获得稳定、可限流的 Iq 扭矩控制。

执行项：

1. 以实测相电阻 R 和电感 L 重新计算 PI 初值。
2. 从小电流阶跃开始，先调 D 轴，再调 Q 轴。
3. 加入电压饱和、积分抗饱和、Iq 限幅和斜坡。
4. 验证正负 Iq、堵转低电流、负载突变行为。

初值估算可采用：

~~~text
Kp 约等于 L × 电流环角频率
Ki 约等于 R × 电流环角频率
~~~

实际值必须根据采样延迟、PWM、电机参数和波形复核，不能直接套用。

验收：

- 小电流阶跃快速收敛且无持续振铃。
- 指令正负号与扭矩正负号一致。
- 电流限幅和故障关断有效。

### 阶段 6：速度环闭环

目标：在限定 Iq 下稳定控制速度。

执行项：

1. 速度环频率设为约 1 kHz。
2. 位置环先关闭，只调速度 PI。
3. 用低速度、小阶跃、再到额定范围的方式整定。
4. 速度目标使用斜坡，避免直接产生过大 Iq。
5. 验证空载、典型负载、扰动下的稳态误差和超调。

验收：

- 目标阶跃不导致电流持续打满。
- 速度反向时无明显失控或反冲。
- 速度估计不被编码器噪声主导。

### 阶段 7：位置环与轨迹规划

目标：实现输出轴给定角度后的快速、平稳、可重复定位。

执行项：

1. 明确位置命令采用输出轴角度还是电机轴角度。
2. 将位置命令转换为连续位置参考，避免单圈跳变。
3. 在位置环前加入速度、加速度限制；更高要求时加入 S 曲线限加加速度。
4. 先调位置 P，利用已稳定的速度环提供阻尼。
5. 仅在存在稳态偏差时，小幅加入位置积分，并配置积分限幅。
6. 限制 Position.OutMax，不要一开始使用额定最高电机轴速度。
7. 对每次模式切换、重新对齐、急停恢复执行无冲击的参考同步和积分清零。

建议测试序列：

1. 输出轴小角度阶跃，例如 5 度、10 度。
2. 中等角度阶跃，例如 30 度、90 度。
3. 正反向连续阶跃。
4. 相同位置连续 20 次往返。
5. 空载和典型负载下重复上述测试。

验收指标由实际需求定义，至少应包含：

- 最大超调；
- 稳态位置误差；
- 进入误差带的整定时间；
- 最大电流；
- 反向时的回差和抖动；
- 故障与限流时的安全行为。

### 阶段 8：负载验证与长期稳定性

目标：证明系统不是“偶然能跑”，而是在目标工况下可交付。

执行项：

1. 在目标负载、目标供电、不同温度下运行。
2. 测试位置保持、外力扰动、通信中断、编码器短暂错误、母线波动。
3. 保存关键波形和最终参数。
4. 写入参数版本、校准步骤、烧录版本和恢复流程。

验收：

- 同一参数在重复上电后行为一致。
- 长时间运行无异常跳变、热保护误触发或通信影响控制。

## 6. MT6816 代码的优化空间

### 6.1 现状中做得正确的部分

当前 BSP 已按 MT6816 数据手册使用 SPI Mode 3、16 位传输，并解析角度、奇偶校验、无磁告警。引脚映射也与项目文档一致。

当前 SPI 分频为 /32，约 5.3 MHz。MT6816 数据手册给出 SCK 周期最小值 64 ns，因此在时钟源为 170 MHz 的前提下，/16 约 10.6 MHz 仍在时序范围内；/8 约 21.25 MHz 则不应直接使用。

升级至 /16 前必须在实际板上检查波形、校验错误率和线缆/布局裕量。

### 6.2 现行实现与剩余风险

1. `BSP_MT6816_PollBlocking()` 在主循环中以 `HAL_GetTick` 门控，最高约 1 kHz 读取并发布双缓冲快照；High_Loop、位置/速度反馈和 VOFA 只读取快照，不再各自发起 SPI。
2. 快照包含状态、序号、采样时间、单圈角、连续角和速度；奇偶、无磁或 SPI 错误会发布错误状态，超过新鲜度阈值也会阻止闭环继续运行。
3. 阻塞传输仍有单次 5 ms 超时。它不在 20 kHz ISR 中，但异常时会阻塞主循环；需要在台架上测量错误恢复、故障关断延迟和命令响应。
4. BSP 内仍保留未接入活动调度的 SPI DMA request/service 路径。2026-08-30 台架曾观察到使能后 DMA 采样失败，因此只有定位根因并复测后才能恢复；当前不能按旧说明声称 2 至 5 kHz DMA 采样已生效。

### 6.3 后续优化顺序

第一步：保持现有缓存边界并补齐台架证据。

- 验证单圈角、连续角、速度、时间戳、错误码和错误计数的更新一致性。
- 保持只有主循环采样路径访问 SPI，控制环与 VOFA 只读取最近完整缓存。
- 验证跨零、反向、多圈和短时丢样，不允许持续失效伪装成“位置未变化”。

第二步：补齐尚未完成的故障诊断。

- 现行代码已实现缓存过期关桥、启动新鲜度预检，以及奇偶/无磁状态和累计计数。
- 为主循环阻塞 SPI 忙/超时增加独立累计计数；再根据实测错误率决定是否需要连续失败阈值，不能用阈值掩盖持续丢样。
- 在台架上测量断线、弱磁、校验错误和 SPI 超时后的关断与恢复时序。

第三步：在证据充分后评估性能路径。

- 现行 SPI 保持 /32；只有用逻辑分析仪确认波形、校验错误率和线缆/布局裕量后，才可试验 /16。
- 若确需恢复 2 至 5 kHz DMA 或 LL 采样，先定位 2026-08-30 的使能后失败根因，再做受控台架复测。
- 现行控制角已经按缓存速度做短时预测；需要验证高速、反向和丢样边界，而不是重复实现同一功能。

第四步：补充可选位置坐标能力。

- 现行 UART 位置环已经使用最近一次对齐零点下的连续电机轴位置。
- 如需上位机直接输入输出轴角，增加明确的接口层换算，不能静默改变现有 `AO` 单位。
- 若需要跨重启绝对位置，另行设计机械回零或多圈保存与一致性校验策略。
- 通过编码器故障注入确认现有状态机锁存与 MOE 关断时序。

## 7. VOFA 刷新慢的原因与优化计划

### 7.1 物理带宽上限

当前 JustFloat 包含 24 个 float 和 4 字节帧尾：

~~~text
24 × 4 + 4 = 100 字节/帧
100 × 10 = 1000 串口位/帧（含起始位和停止位）
921600 / 1000 = 921.6 帧/秒
~~~

当前 921600 波特率下，按最高 500 Hz 计算，100 字节数据帧约占 54.3% 串口位带宽。发送采用 2 ms 最小间隔门控，实际成功帧间隔通常不小于 2 ms；主循环延迟或 UART/DMA 忙时会丢弃过期遥测，不阻塞主控制循环。

相关位置：

- 通道数量：`SguanFOC v3.0.1/Sguan_printf.h`
- 串口波特率：`Core/Src/usart.c`
- DMA 双缓冲与 2 ms 门控：`SguanFOC v3.0.1/UserData_Function.h` 的 `User_CorrespondSet`
- 主循环发送调用：`SguanFOC v3.0.1/SguanFOC.c` 的 `Printf_Normal_Loop`

### 7.2 当前实现与剩余风险

当前实现已经使用专用 DMA 双缓冲：先把 `Sguan.TXdata` 快照复制到空闲发送缓冲，再启动 DMA，因此主循环更新源数据不会撕裂正在发送的帧。

实现约束如下：

1. 先把快照写入空闲 TX 缓冲。
2. 启动 DMA 后，该缓冲在完成回调前只读。
3. DMA 忙时不等待，不覆盖正在发送的帧；可以丢弃过期遥测，只保留最新快照。
4. Ch6 是 20 kHz `g_high_loop_cnt` 的低 16 位计数值；最高 500 Hz 且调度稳定时，相邻成功帧差值通常约为 40，它不是直接帧率。发送失败或主循环延迟会使下一帧差值增大。

### 7.3 分阶段优化方案

第一步：先测量而不提速。

- 用 `ΔCh6` 观察相邻帧间隔：正常 500 Hz 时约为 40；需要帧率时由上位机计算 `20000 / ΔCh6`，并处理 16 位回绕。Ch6 本身不带 Hz 单位。
- 新增或规划 TX 成功、丢弃、完成计数，区分“控制慢”和“遥测慢”。
- 在 VOFA 只开必要通道，避免 PC 端过多曲线渲染造成视觉刷新慢。

第二步：限制最高遥测频率并保持非阻塞。

- 常规调试当前最高为 500 Hz，实际成功发送频率可更低。
- 发送接口已改为 DMA 忙则直接返回，不进行 while 等待。
- 已使用双缓冲，保证帧一致性。
- UART 和 DMA 中断优先级低于 ADC、PWM/控制中断。

第三步：减少帧尺寸。

- 开环/相序调试只发送 6 至 8 个关键通道。
- 电流环调试发送 Id、Iq、Iq_ref、Uq、角度、状态。
- 位置环调试发送 pos_cmd、pos_ref、pos_fb、speed_ref、speed_fb、Iq_ref、Iq、status。
- 不同调试阶段使用不同的固定通道定义，并同步更新 VOFA 工程。

若后续增加更多通道或提高帧率，缩短帧长度仍是最直接的带宽优化方式。

第四步：复核 921600 链路质量。

当前完整 24 通道帧为 `24 × 4 + 4 = 100` 字节；921600-8N1 的理论上限约 921.6 帧/秒，最高 500 Hz 时约占 54.3% 串口位带宽。不要设为 1 kHz，因为已经超过理论上限；2 ms 最小间隔门控为命令、主循环抖动和 UART 调度保留余量。

## 8. 控制参数整定原则

### 8.1 必须遵守由内到外的顺序

调参顺序必须是：

~~~text
电流采样正确
  -> 电流环
  -> 速度环
  -> 位置环
  -> 轨迹和前馈
~~~

外环的带宽必须显著低于内环。实用起点是速度环比电流环慢 5 至 10 倍，位置环再比速度环慢 3 至 5 倍；具体比例依据机械惯量、齿隙、编码器噪声和目标响应调整。

### 8.2 现有默认参数不能直接作为最终参数

UserData_Motor.h 中的 R、L、磁链来自资料和估算，尤其电感量必须用实物确认。任何电感单位、相电感/线电感定义的误解都会让电流 PI 初值相差数量级。

建议保留“资料初值”和“台架实测值”两组记录，不要在没有原始测量记录的情况下直接覆盖。

### 8.3 位置环的推荐首版形态

首版不要追求位置积分和高微分增益。建议：

1. 使用位置 P 产生 speed_ref。
2. 使用稳定的速度 PI 产生 Iq_ref。
3. 使用稳定的电流 PI 产生 Ud/Uq。
4. 用速度、加速度限制约束位置阶跃。
5. 只有确认摩擦导致静差后，再少量增加位置积分。

减速器的回差、摩擦和弹性会限制最终可达到的快速定位性能。若出现高频抖动，优先检查速度估计、位置滤波、机械回差和电流环，而不是先增大 Position.Kp。
