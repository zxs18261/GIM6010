| 项目 | 24V 版 | 48V 版（参考，本工程不用） |
|------|--------|---------------------------|
| 额定电压 | **24 V** | 48 V |

> 电机资料表列出 12~48V 范围，但这不等于本控制板当前台架允许 48V。本工程使用 **24V 版本**并按 24V 标称、限流供电；1/11 母线采样从 ADC 码 4000（名义约 35.45V）起按过量程关断，且 48V 会使 ADC 节点超过 3.3V。禁止据此规格表给当前板直接接 48V。

| 转速常数 | Speed constant | **11.54** | rpm/V | 见下方说明 |
| 扭矩常数 | Torque constant | **0.61** | N·m/A | |
| 极对数 | Number of pole pairs | **14** | 对 | FOC 核心参数 |

### 转速常数说明

厂家标称 **11.54 rpm/V**，结合减速后额定转速 245 rpm（24V）推算，该常数 likely 指**输出轴侧**转速与电压的关系：

```
245 rpm / 24 V ≈ 10.2 rpm/V（接近 11.54 rpm/V 量级）
```

电机轴侧（减速前）额定转速：

```
245 rpm × 8（减速比）= 1960 rpm
```

## 7. SguanFOC 参数映射建议

以下是将厂家参数映射到 `UserData_Motor.h` / `UserData_Config.h` 的建议值。

### 7.1 UserData_Motor.h — 电机实体参数

```c
// 电机实体参数（24V GIM6010）
Sguan.identify.Ld  = 0.23077f;      // H，线电感 230.77mH（Ld≈Lq，表贴/内嵌需实测区分）
Sguan.identify.Lq  = 0.23077f;      // H
Sguan.identify.Rs  = 0.44f;         // Ω，线电阻
Sguan.identify.Flux = 0.02905f;     // Wb，由 Kt 估算：ψ ≈ Kt / (1.5 × P) = 0.61 / (1.5 × 14)

Sguan.motor.Poles  = 14;            // 极对数（⚠️ 原默认 7 错误）
Sguan.motor.VBUS   = 24.0f;         // V，额定母线（⚠️ 原默认 12 错误）
Sguan.motor.Duty   = 4250;          // 与 TIM1 ARR 一致
```

### 7.2 安全限幅建议

```c
// 安全保护（基于 24V 规格）
Sguan.safe.VBUS_MAX = 48.0f;        // 电压范围上限
Sguan.safe.VBUS_MIN = 12.0f;        // 电压范围下限
Sguan.safe.Dcur_MAX = 30.47f;       // 堵转电流（峰值）
Sguan.safe.Qcur_MAX = 30.47f;
Sguan.safe.Current_limit = 6.6f;    // 额定电流
Sguan.safe.Speed_limit = 25.66f;    // rad/s，输出轴额定角速度 (245rpm)
```

### 7.3 减速比与编码器换算

```c
// 软件常量（建议新建或在 UserData 中定义）
#define GIM6010_GEAR_RATIO      8.0f    // 减速比
#define GIM6010_ENCODER_BITS    14      // MT6816 实际位数（PCB）
// 若使用电机模块 16bit 编码器，改为 16

// 输出轴转速 = 电机轴转速 / GEAR_RATIO
// 输出轴角度 = 电机轴角度 / GEAR_RATIO
```

### 7.4 磁链估算过程

```
扭矩常数 Kt = 0.61 N·m/A
极对数 P = 14

表贴永磁同步电机近似：
  ψ = Kt / (1.5 × P)
    = 0.61 / (1.5 × 14)
    = 0.02905 Wb
    ≈ 29.05 mWb
```

> 磁链建议通过实测反电势或 SguanFOC 参数辨识进一步校准。

### 7.5 电流环 PID 初值参考

基于 $L = 230.77\,\text{mH}$，$R = 0.44\,\Omega$，控制周期 $T_s = 100\,\mu\text{s}$（10 kHz）：

| 参数 | 估算思路 | 建议初值 |
|------|----------|----------|
| 电流环带宽 | $f_{bw} = R / (2\pi L) \approx 0.3\,\text{Hz}$（很低，电机为大电感） | 需实测调整 |
| Kp | $L \times 2\pi f_{cc} / 1.5$ | 先用厂家/例程默认，再调 |
| Ki | $R \times T_s / 1.5$ | 同上 |

> **注意：** 230.77 mH 电感较大，电流环带宽会较低，响应较慢。若实物测试发现参数偏差大，建议用 LCR 表或 SguanFOC 辨识功能重新测量 L/R。
