# 第 1 章 需求①：首次上电自学习 + 相线错接自动校正

### 1.1 你想要的最终效果（我已按你的描述理解为）⬜ 请确认或补充
> 控制器**第一次上电（或按触发）时自动驱动电机做一次"预定位/标定"**，把结果（编码器零位偏移、旋转方向、相序重映射等）**存入单片机内部 Flash**；之后每次上电直接加载该结果。
> **目的**：即使电机相线没有按 U/V/W 焊一致，标定后电机也按你的指令方向正常转，不反转、不失控。

### 1.2 物理原理说明（供你理解选项，不需要你填）
电机三相任意接线共有 6 种排列，其中 2 种是"有效相序"（一正一反），4 种会造成堵转/反转/大电流。
软件可以做到的是：**标定阶段试探性地小电流驱动，判断"期望正转 vs 实际转向"，然后把 PWM 三相输出做通道重映射（相当于软件把两根相线交换）+ 存方向标志**，从而覆盖任意接法。边界条件：
- 标定需要电机轴**可自由转动（空载/轻载）**，且电源**限流**（建议 12V、1~2A 起步，见附图确认电源能力）；
- 若机械负载锁死，标定无法完成，需进入错误提示。

| 帧类型 | 方向 | 建议 ID 规划 | 数据字节布局（建议默认，可改） | 确认 |
|---|---|---|---|---|
| ID 请求 Request | 节点→总线(协调者听) | 0x200 + 0（广播用节点0 发，或 0x200 广播） | Byte0=请求节点当前临时号(0xFE 表示无) | ☐ |
| ID 授予 Grant | 协调者→指定节点 | 0x210 + 目标节点号 | Byte0=新分配的 ID，Byte1=0xAA(有效) | ☐ |
| 分配拒绝/总线满 | 协调者→广播 | 0x220 | Byte0=0x01 满 / 0x02 冲突 | ☐ |
| 协调者心跳 COORD_HB | 协调者→广播 | 0x230 | Byte0=0x5A；Byte1=已分配节点掩码低8位；Byte2=…高 | ☐ |
| 节点业务心跳 NODE_HB | 节点→广播 | 0x240 + 节点号 | Byte0=递增计数；Byte1=状态(0运行/1故障/2学习)；Byte2=错误码 | ☐ |
| 冲突通知 | 冲突节点→广播 | 0x250 + 节点号 | Byte0=冲突的 ID | ☐ |
| 业务数据(目标下发) | 协调者→指定节点 | 0x300 + 目标节点号 | 4B float 目标(如位置) + Byte4=目标类型(0位置/1速度/2电流) + Byte5=模式 | ☐ |
| 业务数据(状态回传) | 节点→协调者 | 0x310 + 节点号 | 4B float 实际(位置)+4B float 速度+Byte8=模式 | ☐ |
