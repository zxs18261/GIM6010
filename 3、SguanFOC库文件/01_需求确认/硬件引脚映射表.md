# 硬件引脚映射表（原理图提取）

> 来源：`GIM6010电机SCH_Schematic1_1_2026-07-11.pdf` + `Netlist_Schematic1_1_2026-07-11.tel` + `GIM6010_V0.0.ioc`
> MCU：STM32G431CBT6 (LQFP48)

## 电机驱动（TIM1 互补 PWM → FD6288 栅驱）
| GPIO | 网络 | 功能 |
|---|---|---|
| PA10 | HIN_U | 高侧 U（FD6288 HIN_U） |
| PA9  | HIN_V | 高侧 V |
| PA8  | HIN_W | 高侧 W |
| PB15 | LIN_U | 低侧 U |
| PB14 | LIN_V | 低侧 V |
| PB13 | LIN_W | 低侧 W |

## 电流 / 电压采样（INA181×3 + 分压）
| GPIO | 网络 | 通道 | 采样方式 |
|---|---|---|---|
| PB1  | ADC_IV   | ADC1_IN12 | V 相电流，注入 JDR1 |
| PB0  | ADC_IW   | ADC1_IN15 | W 相电流，注入 JDR2 |
| PB11 | ADC_VBUS | ADC1_IN14 | 母线电压 /11，注入 JDR3 + 常规 Rank0 |
| PB2  | ADC_IBUS | ADC2_IN12 | 母线电流，ADC2 常规 |

## 温度 NTC（2 路）
| GPIO | 网络 | 通道 | 功能 |
|---|---|---|---|
| PA2 | ADC_NTC1 | ADC1_IN3 | **板载 NTC2 → 驱动器温度**（常规 Rank1） |
| PA3 | ADC_NTC2 | ADC1_IN4 | **外部 P1 焊盘 → 电机温度**（常规 Rank2） |

## 编码器 MT6816（SPI3）
| GPIO | 功能 |
|---|---|
| PB3 | SCK |
| PB4 | MISO |
| PB5 | MOSI |
| PA15 | CSN（板载 MT6816 片选） |
| PA4 | CSN（外部编码器座 CN47 片选，备用） |

## 通讯
| GPIO | 功能 |
|---|---|
| PB6 | USART1_TX（921600，VOFA 上行） |
| PB7 | USART1_RX（AO/BO/CO 文本下行） |
| PB8 | FDCAN1_RX（TJA1051） |
| PB9 | FDCAN1_TX |

## 按键
| GPIO | 功能 |
|---|---|
| PG10(NRST) | SW1 = ID 分配键（不按=高 / 按下=低；需 Option Byte `NRST_MODE=GPIO`） |
| PA11 | SW2 = KEY1（预留） |

## 其它
| GPIO | 功能 |
|---|---|
| PA12 | RGB WS2812B 数据线（TIM4_CH2 PWM） |
| PA13 / PA14 | SWDIO / SWCLK 调试 |
| PF0 / PF1 | 8MHz 晶振 OSC_IN / OSC_OUT |

## 备注（供参数换算）
- 三片 INA181：U15(IV)、U19(IW)、U16(IBUS)，增益 20、REF=1.65V（U18 产生 1V65）
- 采样电阻 5mΩ×3：R14(IV)、R16(IW)、R2(IBUS)
- VBUS 分压 R19(3k)/R20(30k) = /11
- CAN 120Ω=R96：本板直连、不软件切换（框架预留切换接口）
- 电流量程 ±16.5A（±1.65V / (20×5mΩ)），12bit LSB≈8.06mA
- 编码器片选：板载用 PA15，外部座 CN47 用 PA4
