# 03 首上电自学习与相序校正设计（草案 v1，待确认）

## 一、目标（需求①）
首次上电（或上位机指令触发）自动标定：**相序自动校正 + 编码器零位 + 电流零偏**，
结果存 Flash；之后上电直接加载，保证方向一致、不反转、不失控。
以**磁编码器读取的正方向为统一正方向**（磁编安装一致）。

## 二、标定内容与存储项
| 项 | 说明 |
|---|---|
| 编码器零位偏移 Pos_offset | 堵转对齐到某电角度时读编码器，记录偏移 |
| Motor_Dir / PWM_Dir / Encoder_Dir | 方向位（±1） |
| Current_Dir0 / Current_Dir1 | 相电流方向（±1） |
| 相序重映射表 | U/V/W 三相软件重排（覆盖任意接法） |
| 相电流零偏 Current_offset0/1 | 0 电流时的 ADC 值（偏置电压，各板不同） |
| 标定完成标志 + CRC + 版本 | 校验有效性 |

## 三、标定流程（空载、24V、限流 2A）
1. **预检**：未使能 PWM，读母线电压、温度、编码器可读 → 否则报错红闪。
2. **电流零偏采样**：PWM 关，采 N 次 ADC 求平均 → `Current_offset0/1`（≈2048）。
3. **方向自学习**：小 Iq 试探（如 0.5A）驱动，观察编码器转向：
   - 与期望正方向一致 → Motor_Dir/Encoder_Dir 记录；
   - 相反 → 翻转方向位，重新验证。
4. **相序自校正**：若方向测试失败（堵转/大电流/不转），软件交换两相 PWM 通道重映射，
   重试直到能按期望方向平稳转动（最多 6 种相序排列），记录最终重映射表。
5. **堵转对齐 + 零位**：施加固定电角度矢量把转子拉到某已知位置，读编码器 → 记录 Pos_offset。
6. **校验**：再次小 Iq 正转/反转，确认方向稳定、电流正常。
7. **写 Flash**：全部参数 + CRC + 完成标志。
8. **完成指示**：绿灯/特定色 + 串口打印"标定完成"；失败→红闪 + 错误码，禁止启动。

## 四、重标定 / 恢复出厂
- 重标定：上位机命令（AO/BO/CO 之外新增，或 MGMT 帧子命令 1=触发标定）。
- 清除标定：长按按键 5s 或 MGMT 子命令 3；清除后上位机收到"已恢复出厂"。
