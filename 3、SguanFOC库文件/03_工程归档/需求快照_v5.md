## 二、硬件事实（见 `01_需求确认\硬件引脚映射表.md`）
- STM32G431CBT6 @170MHz；TIM1 20kHz 互补 PWM（HIN_U/V/W=PA10/9/8，LIN_U/V/W=PB15/14/13，FD6288）
- 采样：3×5mΩ + 3×INA181(增益20,REF1.65V)：IV→PB1、IW→PB0、IBUS→PB2；VBUS=/11→PB11
- 温度：驱动器=PA2(板载 NTC2)、电机=PA3(外部 P1)
- 编码器 MT6816 SPI3，CS=PA15（外部座 CN47 用 PA4）；轴端直装、单圈（14bit）
- USART1 PB6/7 @921600；FDCAN1 PB8/9（TJA1051，120Ω 本板直连不切换）
- RGB WS2812B=PA12；按键 SW1=NRST/PG10(ID 分配)、SW2=PA11(预留)

## 四、需求① 自学习+相线校正（设计见 `02_设计文档\03_`）
- 首次上电自动一次；上位机命令可重标定；空载、24V、限流 2A
- 相序自动校正，以磁编正方向为统一正方向
- 存 Flash：Pos_offset、Motor_Dir、PWM_Dir、Encoder_Dir、Current_Dir0/1、相序重映射表、相电流零偏、完成标志+CRC、版本
- 失败：红闪+错误码，须上位机指令才能重试，失败禁启
- 恢复出厂：长按按键+上位机命令，清除后上位机收到标识

## 五、需求② 三环+上位机（命令见 `02_设计文档\05_`）
- 模式：开环 0x00、电流 0x01、速度 0x02、位置 0x03；MIT 占位 0x04
- 协议：AO/BO/CO + 新增 CAL/FAC/PID；CO=0 停 / CO=1 使能
- 减速比 8:1；单圈编码器；编码器正方向为正；无物理限位（后续加）
- 位置环：输出轴 0~2π/8 + 上电以当前角为参考
- 切模式先停止；PID 在线调参需指定指令进入、默认关闭

## 六、需求③ VOFA（✅ 方案 A，通道见 `02_设计文档\05_`）
- 921600，实际 19 通道 @1kHz（80B，86.8%）；5 备用=编译宏默认不发送
- 19 通道已定稿（心跳/状态/模式/电角度/出轴角/出轴速/给定/DQ给定/DQ实际/U相电流/U相计数值/VBUS/驱动温/电机温/标定标志/CAN ID/CAN心跳）

## 七、需求④ 多机 CAN（帧编码见 `02_设计文档\01_`，状态机见 `02_`）
- TJA1051；本板 120Ω 常连不切换，框架按可切换预留
- 节点 6~8（宏上限 32）；经典 CAN 1Mbps
- 按键 SW1(NRST/PG10)：上电按住=进 ID 分配；不同 ID 匹配完成闪不同颜色；长按 5s=清 ID 常亮白灯
- ID 写 Flash，重复上电直接 ASSIGNED；冲突=全部重新申请
- 参数：超时 500ms/重试 5 次/协调者心跳 100ms/业务心跳 500ms/离线 3 周期
- 状态机：UNASSIGNED→WAITING_GRANT→ASSIGNED，ID==0 加 COORDINATOR
