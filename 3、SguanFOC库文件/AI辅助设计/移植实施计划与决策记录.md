### 电流采样通道 -> 库通道映射（关键）
库 `Current_ReadIabc()`（SguanFOC.c:278-290）语义：
- `Current_Num=0` -> AB 采样：ch0=A，ch1=B
- `Current_Num=1` -> AC 采样：ch0=A，ch1=C
- `Current_Num=2` -> BC 采样：ch0=B，ch1=C

硬件只采 **V 相**与 **W 相** 低边 => 对应库的 B、C 相 => **应设 Current_Num=2**，
`User_ReadADC_Raw(0)` 返回 IV(JDR1)，`User_ReadADC_Raw(1)` 返回 IW(JDR2)。
> 若实际电机相序与丝印 U/V/W 不一致，正转测试时表现为"堵转/反转/电流爆炸"，届时交换 U/V 两相或调 Current_Dir，一次只改一个变量。

## 二、分阶段实施步骤（每步含验收）

### 阶段 0：修复会"一跑就出事"的库缺陷（已完成 ✅ 已用 ARMCC 编译验证）
- [x] PID float/Q31 微分项符号（Sguan_PID.c:73-74, 151-155）
- [x] PID Q31 `Do[0]` 被比例项覆盖 -> 微分丢失（Sguan_PID.c:156）
- [x] MTPA float 公式符号/量级错误 + Ld==Lq 除零保护（Sguan_Optimize.c:15-19, 21-41）
- [x] High-Loop 在 14-18 错误态仍驱动 PWM -> 错误态一律输出归零（SguanFOC.c:1592,1604）
- [x] 清零分支防抖残留：故障→恢复→同号再故障会漏清零 -> 改"进入沿"锁存（SguanFOC.c:1585,1604）
- [x] 看门狗共享 count 进入新状态不清零 -> 状态切换即清零（SguanFOC.c:Status_RUN_Loop）
- [x] PWM_CALC_FAULT(21) 漏出错误态早退范围 -> 扩到 <22（SguanFOC.c:1191）
- [ ] （延后）FDCAN 波特率非标 -> 若用 CAN 再重配
- [ ] （延后）Q31 MTPA/STA/PLL 量纲（Open_Q31_Calculate=0，休眠）

### 阶段 1：接线与空转（电机不接功率）
- [ ] main.c `while(1)` 调 `SguanFOC_main_Loop()`
- [ ] TIM1 更新中断回调 -> `SguanFOC_High_Loop()`
- [ ] TIM2 (1kHz) 中断回调 -> `SguanFOC_Low_Loop()`
- [ ] `User_Delay`（HAL_Delay）
- [ ] `User_CorrespondSet`（USART1 发送）
- 验收：串口可见库初始化打印/状态切换，PWM 未开、电机不转、无大电流。

### 阶段 2：编码器 BSP（MT6816）
- [ ] BSP_MT6816.c：SPI 读 16bit，14bit 角度 -> rad
- [ ] `User_Encoder_ReadRad()` 实现
- 验收：手动转轴，串口打印角度连续变化。

### 阶段 3：ADC BSP（两相电流 + VBUS）
- [ ] `User_ReadADC_Raw(0/1)` 读 JDR1/JDR2
- [ ] `User_VBUS_DataGet()` 读 JDR3 或常规组，×11 还原
- 验收：静止时两路 ADC≈2048；24V 母线 -> VBUS≈24V。

### 阶段 4：参数核对/填写
- [ ] UserData_Motor.h：VBUS=24、Amplifier=20、保护窗 20~26V、Current_Num=2、Dcur/Qcur_MAX≤16A
- [ ] 电流量程与 OC 阈值对齐
- 验收：静态电流换算合理。

### 阶段 5：首次通电开环（限流 12V、1~2A）
- [ ] mode=Velocity_OPEN，小 Uq
- 验收：平滑转、电流波形正常、无啸叫/爆炸（此步过=相序/方向全对）。

### 阶段 6：闭环逐级解锁
- [ ] 电流单环 mode=1 -> 整 Kp/Ki
- [ ] 速度环 mode=2（STA）-> 整 k1/k2
- [ ] 位置环 mode=3（先确认 PID D 符号修复生效）
- 验收：各环阶跃跟踪。

### 阶段 7：上位机/保护/收尾
- [ ] User_UserTX 填 12 通道 JustFloat
- [ ] 过流/过压/温度真实阈值 + 急停输入
- [ ] 可选项：FDCAN 重配 500k/1M
