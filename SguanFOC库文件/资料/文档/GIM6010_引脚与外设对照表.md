## 3. 功能模块详解

### 3.1 三相 PWM 驱动（TIM1 → 栅极驱动器 U2）

```
MCU TIM1                    栅极驱动 U2              MOSFET 半桥
─────────────────────────────────────────────────────────────────
PA8  TIM1_CH1  (HIN_W)  →  U2.24  →  HOW  →  W 相上桥
PA9  TIM1_CH2  (HIN_V)  →  U2.23  →  HOV  →  V 相上桥
PA10 TIM1_CH3  (HIN_U)  →  U2.22  →  HOU  →  U 相上桥
PB13 TIM1_CH1N (LIN_W)  →  U2.3   →  LOW  →  W 相下桥
PB14 TIM1_CH2N (LIN_V)  →  U2.2   →  LOV  →  V 相下桥
PB15 TIM1_CH3N (LIN_U)  →  U2.1   →  LOU  →  U 相下桥
TIM1_CH4 (无输出)       →  触发 ADC 注入采样
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 计数模式 | Center Aligned Mode 1 | 中心对齐，适合 FOC |
| Prescaler | 0 | 无预分频 |
| Period (ARR) | 4250 | 满占空比基准 |
| Dead Time | 9 | 死区时间 |
| CH4 模式 | PWM2，无引脚输出 | 用于 TRGO → ADC 触发 |
| Master Output | TIM_TRGO_OC4REF | 触发 ADC1 注入转换 |
| PWM 频率 | ≈ 20 kHz | 170MHz / (2×4250) |

**SguanFOC 对应：**
- `User_PwmDuty_Set()` → 写 TIM1 CH1/CH2/CH3 比较值
- `Sguan.motor.Duty = 4250`（`UserData_Motor.h`）
- `SguanFOC_High_Loop()` → 挂 TIM1 更新/比较中断

---

### 3.2 电流采样（双电阻 + 母线检测）

采用**下桥臂双电阻采样**方案：采 V 相、W 相电流，U 相由 $I_U = -(I_V + I_W)$ 推算。

| ADC 通道 | GPIO | 采样信号 | 硬件来源 | 转换类型 | 触发方式 |
|----------|------|----------|----------|----------|----------|
| ADC1_IN12 | PB1 | IV | U15 运放（V 相 shunt R14） | **注入** Rank1 | TIM1_CC4 上升沿 |
| ADC1_IN15 | PB0 | IW | U19 运放（W 相 shunt R16） | **注入** Rank2 | TIM1_CC4 上升沿 |
| ADC2_IN12 | PB2 | IBUS | U16 运放（母线 shunt R2） | 常规 Rank1 | 软件触发 |
| ADC1_IN14 | PB11 | VBUS | R19/R20 电阻分压 | 常规 Rank1 | 软件触发 |
| ADC1_IN3 | PA2 | NTC1 | NTC2 热敏电阻 | 常规 Rank2 | 软件触发 |
| ADC1_IN4 | PA3 | NTC2 | P1 外部 NTC | 常规 Rank3 | 软件触发 |

**电流采样硬件参数（默认值）：**

| 参数 | 值 | 位置 |
|------|-----|------|
| 采样电阻 | 5 mΩ | R2 / R14 / R16 |
| 运放增益 | 10 倍 | U15 / U16 / U19 |
| ADC 精度 | 12 位 (4096) | — |
| ADC 基准 | 3.3 V | MCU VDDA |
| 运放参考 | 1.65 V | U18 产生 |
| 电流通道配置 | `Current_Num = 1` | 1 = AC 相（Iv + Iw） |

**SguanFOC 对应：**
```c
// User_ReadADC_Raw 映射建议
case 0: return ADC1_InjectedRank1;  // Iv (PB1, ADC1_IN12)
case 1: return ADC1_InjectedRank2;  // Iw (PB0, ADC1_IN15)
```

### 3.3 磁编码器 MT6816（SPI3）

| 信号 | GPIO | 连接到 | 说明 |
|------|------|--------|------|
| CSN | PA15 | U3 Pin1 | 软件片选，低有效 |

| MOSI | PB5 | U3 Pin5 | SPI3 数据输出 |

| 参数 | 当前 CubeMX 值 | **建议值（移植时修改）** |
|------|---------------|------------------------|
| SPI 模式 | Master | Master |
| 数据位宽 | **4 Bit** ⚠️ | **16 Bit** |
| 时钟极性 | CPOL=Low | CPOL=Low |
| 时钟相位 | CPHA=1Edge | CPHA=1Edge |

| NSS | Soft | Soft（PA15 手动控制） |

**SguanFOC 对应：**
- `User_Encoder_ReadRad()` → SPI3 读 MT6816 14 位角度 → 转换为 0~2π 弧度
- `Sguan.motor.Encoder_Dir` → 根据实物方向设为 1 或 -1

## 4. CubeMX 外设配置速查

### 4.1 外设启用列表

| 外设 | 状态 | 用途 |
|------|------|------|
| ADC1 | ✅ | 电流注入采样 + VBUS/NTC 常规采样 |
| ADC2 | ✅ | IBUS 常规采样 |
| TIM1 | ✅ | 三相 PWM + ADC 触发 |
| TIM4 | ✅ | RGB LED PWM（**低频环需另配或改 Period**） |
| SPI1 | ✅ | 外部 SPI（CN47） |
| SPI3 | ✅ | MT6816 磁编码器 |
| USART1 | ✅ | 调试串口 + DMA |
| FDCAN1 | ✅ | CAN 总线 |
| DMA | ✅ | USART1 TX/RX |

### 4.2 ADC1 详细配置

```
模式：Independent（独立模式）
分辨率：12 Bit
扫描：Enable（常规通道扫描）

【注入通道 — FOC 电流环】
  Rank1: ADC1_IN12 (PB1) → Iv
  Rank2: ADC1_IN15 (PB0) → Iw
  触发：TIM1_CC4 上升沿
  采样时间：47.5 Cycles

【常规通道 — 慢速采样】
  Rank1: ADC1_IN14 (PB11) → VBUS
  Rank2: ADC1_IN3  (PA2)  → NTC1
  Rank3: ADC1_IN4  (PA3)  → NTC2
  触发：软件启动
  采样时间：47.5 Cycles
```

### 4.3 TIM1 详细配置

```
Mode：Center Aligned Mode 1
Prescaler：0
Period：4250
Clock Division：DIV2
Dead Time：9
Break：Disable
Automatic Output：Enable

CH1/CH1N：PWM Generation → HIN_W / LIN_W
CH2/CH2N：PWM Generation → HIN_V / LIN_V
CH3/CH3N：PWM Generation → HIN_U / LIN_U
CH4：PWM2 No Output → ADC Trigger (OC4REF)

Master Output Trigger：OC4REF
中断：BRK / UP / TRG_COM / CC 均已 Enable
```

### 4.4 TIM4 详细配置

```
Mode：Up Counter
Prescaler：0
Period：65535
CH2：PWM → RGB LED (PA12)

⚠️ 当前 TIM4 未配置为 SguanFOC 低频环定时器。
   移植时需修改 Period 产生 1kHz 左右中断，或改用其他定时器。
   建议：Prescaler=169, Period=999 → 170MHz/170/1000 = 1kHz
```

### 4.5 SPI 详细配置

```
SPI1（外部 SPI）：
  Mode: Master, Full-Duplex, Soft NSS
  Prescaler: /4, DataSize: 4Bit ⚠️

SPI3（MT6816）：
  Mode: Master, Full-Duplex, Soft NSS
  Prescaler: /4, DataSize: 4Bit ⚠️
  → 移植时必须改为 16Bit
```

### 4.6 USART1 详细配置

```
Mode: Asynchronous
BaudRate: 115200
Word Length: 8 Bits
Stop Bits: 1
Parity: None
DMA: TX=DMA1_Ch1, RX=DMA1_Ch2
```

### 4.7 FDCAN1 详细配置

```
Frame Format: Classic CAN
Mode: Normal
Nominal Prescaler: 16
Nominal TimeSeg1: 1, TimeSeg2: 1
→ 计算波特率 ≈ 3.54 Mbps
```

### 4.8 RCC 时钟树

```
HSE：8 MHz（X1 晶振）
PLL：M=÷2, N=×85, R=÷2
SYSCLK：170 MHz（PLL）
AHB：170 MHz
APB1：170 MHz（Timer 时钟 = 170 MHz）
APB2：170 MHz（Timer 时钟 = 170 MHz）
ADC12 Clock：SYSCLK
```

### 4.9 NVIC 中断优先级

| 中断 | 优先级 | 用途 |
|------|--------|------|
| ADC1_2 | 1 | ADC 转换完成 |
| TIM1_BRK / UP / TRG / CC | 0 | **SguanFOC 高频环** |
| DMA1_Ch1 / Ch2 | 0 | USART DMA |
| SysTick | 15 | HAL 时基 |

## 8. 待确认 / 移植注意事项

### ⚠️ 必须在移植时修改

| 项目 | 当前状态 | 需要改为 |
